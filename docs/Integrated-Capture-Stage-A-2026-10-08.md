# Panzo 一体化捕获：第一阶段实现与使用说明

日期：2026-10-08。范围对应 [整体方案](Panzo-Integrated-Capture-Plan-2026-10-08.md) 的 A 阶段，并包含本次要求的功能菜单首页。

## 启动

双击 `target/integrated-stage-a/release/panzo.exe`。

开发启动：在仓库根目录运行 `cargo run -p panzo-app --bin panzo`。本机 Cargo 若未加入 PATH，可用：

```powershell
& "$env:USERPROFILE\.cargo\bin\cargo.exe" run -p panzo-app --bin panzo
```

旧候选 `target/editor-feedback/release/panzo.exe` 保留。

## 已实现

| 功能 | 第一阶段行为 |
|---|---|
| 功能菜单 | 默认进入截图、录屏、贴图、最近内容、打开图片、打开工程六个入口；编辑器主菜单可返回功能菜单 |
| 共享选区 | 拖动框选，方向键微调位置，Shift + 方向键调整尺寸；Enter 确认，R 将同一选区用于录屏，Esc 取消 |
| 截图 | 截图后打开轻量图片窗口，支持矩形、箭头、画笔、文字、马赛克、实色遮挡、撤销/重做、复制、PNG 保存、贴图 |
| 贴图 | 图片置顶、拖动、滚轮缩放、Ctrl + 滚轮调透明度；双击隐藏，右键复制/保存/编辑副本/隐藏/关闭；Space 打开编辑副本 |
| 区域录屏 | 单显示器内固定矩形；编码尺寸向内取偶数，不扩大选区；进入编码纹理前裁剪，区域外点击不持久化，区域外鼠标位置以隐藏状态处理 |
| 缩放开关 | 录前开启/关闭并记住选择，工程继承设置，录后仍可在编辑器调整。当前镜头按点击聚焦，连续鼠标跟随留待 C 阶段 |
| MP4 | 30 / 60 FPS；原始/画布尺寸、1080p、宽度不超过 1280 / 640 的等比例分享尺寸 |
| GIF | 10 / 15 / 20 / 25 / 30 FPS；同一编辑合成流程输出，默认紧凑尺寸、无限循环；编码器随程序编入，不要求安装外部软件 |
| 最近内容 | 本地最近 20 个录屏工程与截图；复制截图或保存时留存 PNG 副本；默认库为 `%USERPROFILE%\Videos\Panzo` |
| 托盘 | 打开功能菜单、截图、区域录屏/停止、贴图及显隐、隐藏主窗口、退出；退出沿用录屏收尾和工程保存流程 |

全局快捷键：

- `Ctrl + Shift + S`：截图。
- `Ctrl + Shift + R`：选择录屏区域；正在录屏时请求停止。
- `Ctrl + Shift + P`：贴出剪贴板图片。
- `Ctrl + Shift + H`：全部贴图显隐。

快捷键占用时，首页状态会提示，可继续从菜单操作。截图选择后需要按 Enter；文字工具先在上方文本框输入，再点击图片放置。导出先选格式/帧率、尺寸和文件位置，再点击导出。

## 实现要点

- 保留原生 Win32 主窗口与既有工程编辑器。截图窗口按需创建，首页不初始化视频解码器，空闲时不持续重绘。
- 截图和区域录屏共用物理像素坐标；区域素材尺寸、事件坐标与工程元数据保持一致。
- MP4/GIF 复用已有帧求值和合成器，保留裁剪、变速、镜头、光标、画布和背景设置。
- MP4 分享输出采用随尺寸、帧率调整的码率，录制素材的质量配置保留。GIF 直接编码合成帧，无须 MP4 中转。
- 导出写临时文件，成功后发布；拒绝覆盖已有成品，取消或失败清理本次临时输出。
- 图片保存和复制输出已合并标注的像素。原图及撤销记录仅留在当前图片窗口内，不写入导出的 PNG。

## 后续范围与当前边界

第一阶段提供基础可用流程，尚未达到 Snipaste 完整体验。智能窗口/控件吸附、像素放大镜与取色、贴图分组和跨启动恢复、鼠标穿透及恢复入口归入 B 阶段；滚动截图、OCR、录制音频、暂停、连续鼠标跟随、录中镜头切换及外部视频导入继续按整体路线图实施。

截图窗口目前是基础原生工具栏；关闭时未复制、未保存的图片编辑不会保留。剪贴板贴图支持常见 24/32 位 RGB DIB；其他格式可先通过“打开图片”载入 PNG/JPEG/BMP。跨屏录屏暂不支持。GIF 帧延时按其百分之一秒粒度分配，播放速度也受查看器影响。

本轮验证发生在当前 Windows/GPU 上；混合 DPI 多显示器实机、长时录制、干净 Windows 安装、多 GPU 与性能门槛尚未作为本轮通过项。
