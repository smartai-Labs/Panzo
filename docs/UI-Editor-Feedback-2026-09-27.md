# 编辑器操作反馈修复

本轮优化现有错误处理与提示，不增加编辑功能或独立通知模块。用户描述的某次偶发错误没有明确操作序列，不能认定所有底层故障均已排除。

## 已确认并处理的问题

- 去掉把所有错误替换成“操作未完成，当前修改仍保留”的统一显示；按实际操作展示中文说明，完整技术原因进入现有设置 → 诊断详情。
- 取消导出在工作线程边界保留独立类型，正常取消不会显示导出失败；预览准备被取消时不报错、不计入媒体错误，也不打断新操作。
- 已成功回退到兼容预览时显示普通状态；编辑校验失败和修改成功后的预览失败分别处理，不把所有失败都描述成编辑未生效。
- 片段边界不能分割、最后一个视频片段不能删除：按钮与快捷键入口提前检查，避免先执行再返回验证错误。
- 数字范围、颜色和镜头范围校验使用中文说明。内联输入错误保留输入及原值，在字段附近显示改正方法和 Esc 取消提示；取消后立即清理输入提示。
- 保存、恢复副本、导出、背景和预览各自保留未解决状态。保存失败优先显示，不受参数调整等无关成功状态覆盖；实际保存成功才解除，成功呈现画面才解除预览问题。
- 普通消息约 8 秒后恢复就绪/未保存状态。相同问题合并，诊断保留最多 16 条且每条限制 4096 字符；底部状态使用可用整行宽度。
- 恢复副本轮询区分“暂无结果”和“写入完成”，不能用空轮询误清除失败。完整修改已经手动保存时，解除旧的恢复副本提醒。

## 涉及位置

`editor_ui.rs` 管理反馈与诊断；`preview_window.rs` 管理任务状态及错误分流；`editor_widgets.rs`、`editor_chrome.rs` 和 `editor_layout.rs` 处理输入提示；`editor.rs` 提供编辑错误中文表达；`workbench_actions.rs`、`editor_tasks.rs`、`editor_draft.rs` 处理取消与保存结果；导航、布局持久化和裁剪入口复用明确的用户提示。
