# Panzo Editor UX Foundation 升级报告

执行日期：2026-09-01（Asia/Shanghai）

## 结论

本轮完成 Editor Workbench 的第一层交互性能升级。长工程时间线不再依赖整段固定像素映射，暂停窗口不再空转重绘，拖动与滚轮不再为每个输入点创建 Undo 状态，D3D11 合成器也不再逐帧重复创建稳定资源。

本轮没有声明视觉设计重构或 GPU 直出完成。2560×1440 播放仍受 GPU Readback、CPU BGRA Copy 和 GDI `StretchDIBits` 限制；这些是下一轮升级的主要对象。

## 已交付

- 新增独立 `TimelineViewport`，提供 Fit、锚点缩放、水平平移、播放头跟随以及 Tick/Pixel 双向映射。
- Timeline Segment 拖动期间只绘制草稿边框，释放后提交一次编辑；Canvas 焦点拖动同样在释放后提交。
- Preview 滚轮缩放按 160 ms 静默窗口合并，期间只修改内存草稿和属性脏区，最终执行一次合成并生成一个 Undo 状态。
- 鼠标拖动使用局部 `InvalidateRect`；小脏区直接绘制，不再为每次移动创建全窗口双缓冲 Bitmap。
- Paused Timer 只维护窗口生命周期，不触发帧渲染和 Paint。
- 背景图片只在背景设置变化时重新解析/解码；普通 Camera 编辑沿用已解码背景。
- D3D11 Compositor 缓存源输入纹理、背景纹理、输出纹理、Render Target View 和 Staging Texture，并提供缓存计数。
- Preview Smoke 输出平均/最大渲染耗时与五项缓存指标。
- `verify-editor-mvp.ps1` 增加 Paused Smoke 和缓存回归门槛，并支持隔离 `TargetDir`。

## 2560×1440 实测

同一工程、同一机器、5 秒窗口自动验收：

| 场景 | 升级前 | 升级后 | 结果 |
|---|---:|---:|---|
| Debug Paused 渲染/绘制 | 约 199 次 | 1 / 1 次 | 消除空转 |
| Debug Playing | 约 27 FPS | 159 帧 / 5 秒（约 31.8 FPS） | 改善 |
| Release Playing | 约 30.6 FPS | 158 帧 / 5 秒（约 31.6 FPS） | 小幅改善 |
| 背景解码 | 无计数 | 1 次 | 有界 |
| 背景纹理上传 | 无计数 | 1 次 | 有界 |
| 输出纹理分配 | 无计数 | 1 次 | 有界 |

升级后播放态平均合成耗时约 20.7 ms，首次渲染约 83～89 ms。Release 未明显拉开 Debug，进一步证明当前上限主要来自同步 GPU Readback 与 GDI 呈现，而不是 Rust 优化级别。
