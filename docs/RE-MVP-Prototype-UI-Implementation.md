## 本轮依据与边界

用户确认的 [index.html](prototypes/re-mvp/index.html)、style.css 和 app.js 是本轮布局与控件基准，原型文件不修改。使用设计系统提取技能整理了 [.stitch/DESIGN.md](../.stitch/DESIGN.md)，将原型的颜色、尺寸、字体和交互映射到现有原生窗口，而不是另做一套设计。

保留 Rust / Win32 Host、独立 HWND / DXGI 预览、后台解码与导出；本轮不是 WebView2 或完整 Direct2D / DirectWrite 迁移。Windows 标题栏、文件选择器、原生输入框和下拉框仍保留系统行为，不仿造 Apple 字体或窗口控制键。ADR-0002 的候选比较与放行条件没有被本轮实现自动关闭。

## 交互与数据保证

- 命令按钮的按下态只持续到释放；开关/标签的选中态单独表示真实状态。
- 标签切换只改变属性面板，不直接替换项目背景；选择色块或图片才修改工程。
- 时间/倍率使用原生 EDIT：选中、复制粘贴、中文输入法与文字快捷键在输入框内处理。Enter 应用，Esc 放弃；输入不合法时保留文本。窗口尺寸或 DPI 改变时取消未提交输入，避免遗留错位输入框。
- 打开输入框但不修改就退出，不提交编辑、不改变原始高精度时间、不触发媒体定位；不能把三位小数显示精度写回原始数据。
- 外观滑杆沿用统一编辑事务；拖动节流，松手提交完整结果，一次拖动只产生一次撤销；Esc/捕获丢失取消草稿。
- 属性滑杆/时间线缩放提供 UIA RangeValue 与左右键操作。隐藏控件不进入焦点顺序，原有命令 ID 保持稳定。
- 导出继续使用独立 ExportTask；文件选择、配置与进度不引入逐帧 UI 跨进程传输。已有输出仍拒绝覆盖，失败/取消不删除既有文件。
- 原始 MP4、鼠标及点击数据不改写。录制分辨率、剪辑映射、撤销与保存事务未降低验收门槛。
