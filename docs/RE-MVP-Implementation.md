# RE-MVP 连续开发实现说明

更新：2026-09-05。本文说明候选实现，不代表发布验收通过。最终结论见根目录 Acceptance-Report.md。

2026-09-26 同步：本页主窗口、导航和导出流程已按当前实现更新；其余阶段性实现记录保留原有范围，当前操作以 [使用说明](RE-MVP-User-Guide.md) 为准。

## 已接通的产品流程

显示器或窗口录制 → 媒体完成收尾 → 自动打开编辑器 → 裁头尾 / 分割 / 删除闭合 → 镜头与外观调整 → 显式保存 / 保存后重开 → 当前编辑快照导出。

新录制默认展示原始画面；自动初稿保留为可选效果。Planner 失败时保留视频并允许无镜头编辑。录制中改变窗口尺寸仍会明确失败并保留可恢复工程，不声称支持动态尺寸重配置。

录制准备与编辑使用同一个主窗口和消息循环。标题栏固定设置、新录制、打开工程入口；录后进入编辑器，点击新录制返回准备，只有关闭主窗口才请求退出应用。切换工程和退出共用未保存处理，取消或保存失败保留当前有效工程。打开工程在后台准备媒体，完成后在原主窗口切换内容，失败保留当前工作区。文件选择器与临时确认仍为系统对话框。

## 编辑数据与安全

- 不改写源 MP4、鼠标轨迹或点击记录。workbench.json 的 schemaVersion 升为 2。
- video 保存 sourceDurationTick 与有序 clips；每段包含稳定 id、sourceInTick、sourceOutTick。区间左闭右开、正时长、保持源顺序、不重叠。
- 分割保留左段 ID，生成右段 ID；删除自动闭合，不能删除最后一段。时间线使用 Project Time，媒体 / 镜头 / 光标使用映射后的 Source Time。
- 镜头范围仍锚定源时间，在保留视频上投影显示；删除区间的点击不显示。cameraEnabled 旁路不删除自动初稿。
- 视频、镜头、背景、画布样式、光标共用 100 步完整状态撤销栈。拖动使用 Before / Draft / Commit，Esc 和捕获丢失取消草稿，正常松手只提交一步。
- v1 打开时不落盘升级；首次保存升级。未知版本拒绝写入。保存沿用多文件事务，新剪辑状态纳入同一修订。
- 同工程写入使用操作系统文件锁和修订冲突检查。后台保存只确认提交的快照，不抹掉保存期间产生的新修改。失败时保留编辑窗口和当前修改。
- 背景图片复制到工程 assets，不能依赖外部路径；文件读取上限 64 MiB，解码前检查尺寸与像素数。只有派生缓存和本次创建的临时输出可以由失败清理移除。

## UI 与媒体任务边界

正式候选仍为 Rust / Win32 Host / 独立 HWND-DXGI 预览，不是 HTML 原型，也没有迁移到 WebView2。新增 / 分离的职责：

| 模块 | 职责 |
|---|---|
| video_edit / FrameEvaluator | 视频片段、时间映射、共享效果求值 |
| decode_worker / preview_scheduler | 有界请求合并、取消、缓存和拖动完成帧接收 |
| preview_proxy / timeline_thumbnails | 本地短 GOP 代理、异步可见区缩略图 |
| editor_clock / presentation_metrics | 独立帧时钟、有限软件 Present 采样 |
| editor_tasks | 保存、背景读取、导出后台任务与结果交付 |
| editor_layout / editor_ui / edit_gestures | DPI 布局、字体与 SVG、按钮状态、拖动范围约束 |
| workbench_actions / editor_dialog | 编辑命令与高级属性表单 |
| editor_chrome / editor_widgets / inline_input | 原型绘制、滑杆/色块/开关、原生内联输入与事务交接 |
| export_window | 主窗口内的非模态子面板，显示导出配置、进度/取消/结果，保持后台 ExportTask |
| accessibility | UIA 独立状态快照、稳定控件身份、有界命令队列和辅助技术通知 |

预览、解码、保存、导出均有各自所有权；窗口析构不无限等待后台线程。主预览采用 GPU 直出，缩略图的 CPU 解码不等于主合成输出 Readback。保留 Win32 不代表 UI 架构与可访问性已经完成验收，见 ADR-0002。

自绘控件已提供中文 UI Automation 语义：命令、镜头开关、播放位置与视频 / 镜头选择。查询只读取快照；操作交回 UI 线程且有队列预算，不能从读屏线程进入解码或编辑模型。窗口关闭、片段删除、模态禁用和焦点变化均有独立处理。暂停编辑器在初次 Ready 前就发布控件树，无需先点击或按键。实现及实机工具边界见[可访问性记录](RE-MVP-Accessibility-Report.md)；读树成功不代表完整读屏或视觉验收通过。

### 资源预算与冷态行为

- 解码 worker 最多 8 个；普通帧缓存每 worker 64 MiB。缩略图独立缓存最多 40 张，缩略图解码缓存 2 MiB。
- 指针请求保留最新目标；近似拖动结果必须满足方向和时间误差约束；松手回到原媒体精确帧。
- 播放最多预读后续两帧，仍受同一 64 MiB 缓存限制；帧完成先交付，预读遇新请求可取消。时钟按实际源 PTS / 剪辑切口唤醒，避免固定 60 Hz 与 10/20 ms VFR 产生重复帧停留。
- 代理在项目 cache/scrub-v1 内，640 像素长边、最多 30 fps、短 GOP；单份视频最大 512 MiB，索引最大 8 MiB。源尺寸和源 PTS 单独保留。
- 每进程最多一个代理生成任务，跨进程使用缓存生成锁。关闭取消生成，失败保留原素材回退；首次准备与已有代理的热态测试分开记录。
- 播放、拖动或导出期间，代理生成在样本边界暂停并让出资源；空闲后继续。暂停等待不持有 GPU 锁，关闭可取消。其实际冷态收益需要完整后测。
- 代理绝不进入最终导出；小窗口 / 低分辨率代理不改变源媒体尺寸。不能把热代理表现外推成首次打开所有长工程均已达到性能门槛。

## 外观与操作

浅灰工具区、白色属性面板、深色独立预览区，中文系统 UI 字体及统一 SVG。强调色按已确认原型为 #087bfa；没有捆绑 Apple 字体或模拟红黄绿窗口按钮。

本轮按已确认原型完成原生结构重排，详见[落地说明](RE-MVP-Prototype-UI-Implementation.md)。时间码移至预览下方，标尺、轨道、内联参数和状态行分区；小窗口折叠属性栏，属性菜单仍可访问。时间线有视频 / 点击 / 镜头轨道、异步缩略图、滚动条和高度调整。实际截图、字体观感、输入法、弹窗及 DPI 矩阵仍需真实桌面验收，纯几何测试不能替代。

错误在底部优先显示简短中文摘要，不被镜头诊断盖住；完整技术信息可通过“更多设置 → 诊断详情”查看，并用 Ctrl+C 复制。镜头诊断按剪辑后的源时间映射求值，旁路时显示基础画面参数。

常用操作：

- 空格播放 / 暂停；单击或拖动标尺定位，松手精确收敛。
- 视频主体选择；两端裁剪；B 分割；Delete 删除所选对象。
- Ctrl+Z / Ctrl+Y 撤销 / 重做；S 保存；Esc 取消当前操作，不再隐式保存关闭。
- Ctrl+滚轮缩放时间线；滚轮、中键拖动、水平滚动条平移；“适应全部”恢复跟随。
- 镜头操作在镜头轨道附近；画布直接调焦点，滚轮调倍率；数值按钮打开带单位和范围检查的属性输入。
- 外观包括纯色 / 图片、边距、圆角、阴影、光标显示和倍率；输错值时保留输入供修正。

## 导出

编辑器内创建不可变快照，包含尚未保存的当前编辑，不强制关闭编辑器。默认原始媒体尺寸，另提供 1920×1080 / 60 fps。等比容纳、不拉伸、不因画布变大无意义放大源；不增加音轨。

导出配置、真实后台进度和取消位于同一主窗口子面板，面板位于共享标题栏下方。“收起”或 Esc 隐藏面板，重新点击导出恢复面板，均不隐式取消任务；取消使用独立按钮。开始前提交有效输入并刷新尺寸和时长，运行后参数与当前任务的不可变快照保持一致。采用同目录唯一临时文件，成功完成才发布最终 MP4；已有同名输出拒绝覆盖。取消 / 失败不删除原有成片。完成后可打开文件位置。

新回归除完整解码、时长 / 帧数 / PTS 外，检查首帧、切口前后和末帧：实际 PreviewSession 路径与导出帧循环的未压缩 Hash 比较，以及 H.264 再解码内容误差。不将有损编码文件与未压缩图像做精确 Hash 比较。

## 验证入口与限制

统一自动回归入口为 scripts/verify-recording-editing.ps1；只操作测试副本。加 -Extended 会显示测试动画并执行新 60 秒录制 / 播放、30 分钟录制和 5 次恢复。

跨 GPU、音频、多轨 / 变速 / 字幕、自动镜头自然度专项保持 Deferred。当前实测 Windows 10 / RTX 4080 SUPER，不代表 Windows 11 或其他 GPU 已通过。真实 UI 操作、视觉确认和端到端可见延迟必须独立记录。
