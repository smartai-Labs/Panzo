## 1. 判断

当前主题已经可以继续使用。主要差距在于：**界面仍按功能逐项排列，尚未稳定地围绕“正在处理什么、下一步做什么”组织。** 用户需要在多层工具条、表单和时间线之间寻找对应关系，内容区因此损失空间。

v13 已完成一批真实改进：统一 Inspector、全宽轨道、固定媒体操作区、类型化表单、主题与重绘基础。本轮不把这些已完成事项重新记作未修复缺陷。商业设计还需要在这些基础上统一任务结构和布局规则；这与“换一套颜色、增加圆角”是不同的工作。

本次判断基于当前源码与 v13 实际窗口证据；原型截图单独列出。没有进行正式用户研究，以下“寻找成本”“理解负担”是界面评审结论，不是测得的用户效率数据。

## 2. 布局问题与对应调整

下列 L 编号属于本轮布局审查，独立于上一轮 A01—A12 的代码整改记录。P1 为结构改造优先项；P2 为完成结构后统一的细节。

| 编号 / 优先级 | 当前问题与依据 | 对用户的影响 | 调整方案 |
|---|---|---|---|
| L01 / P1 | 图片页面同时出现工作区导航、功能工具条、文档导航、参数区域；见图片截图与 image_workspace 的布局 | 上下多层都像工具栏，用户难以判断哪层控制当前图片；画布开始得过低 | 全应用固定为标题菜单、工作区导航、上下文栏三层；图片工具放左侧窄栏，具体参数进入右栏 |
| L02 / P1 | 图片同时保留顶部文档标签和底部文档缩略图导航；只有一张图时也会重复占位 | 同一文档有两个选择入口，底部空间没有相应价值 | 普通图片只保留一套文档标签；底部缩略图仅在拼图等需要管理多张源图的任务中出现 |
| L03 / P1 | 项目画面、视频片段参数、轨道选择与编辑命令分散；轨道上方另有入出点参数行 | 参数的作用对象不够直接；时间线可用高度被参数占用 | 按“项目 / 选中对象 / 视图”明确归属；视频标签改为“片段”，入出点进入所选片段属性；时间线保留剪辑命令 |
| L04 / P1 | 右侧四个标签已统一为一个宿主，但各页仍主要按长表单排列 | 常用操作和次要参数同级；用户必须滚动寻找关键内容 | 统一为对象摘要、常用参数、折叠高级项、固定任务操作四段；图片右栏随当前工具变化 |
| L05 / P1 | 声音页承载导入、设备、录制及相关参数，轨道又承担素材选择 | “获得一段声音”和“修改已有声音”仍容易混淆 | 声音页负责导入、设备检测、录制与结束；音量、淡入淡出、时间范围通过选中音轨后进入片段属性；删除、分割留在轨道 |
| L06 / P1 | 字幕页先展示来源与整份字幕列表，当前字幕编辑靠后；见字幕截图 | 最频繁的校对操作需要向下寻找 | 来源操作压缩为一行；前置当前字幕文字与时间；全部字幕列表、全局样式可展开；应用操作固定底部 |
| L07 / P2 | 素材库已有预览与筛选，但列表、预览的空间权重偏向单个预览，接入编辑的动作不突出 | 查找一批素材与使用当前素材的路径不连贯 | 分类 / 网格或列表 / 有限宽预览三栏；在预览底部明确“在图片工具中打开”或“添加到当前项目” |
| L08 / P1 | 尺寸约束分布在各工作区，缺少统一的缩窄优先级；已有小窗口修复主要保证单个控件可见 | 后续增加功能时容易重新出现挤压、堆叠和多余留白 | 定义统一最小宽度、侧栏上下限、轨道高度上限、内容滚动策略；小窗口先收起辅助素材栏，保留恢复入口 |
| L09 / P2 | 文档状态、当前选择、任务状态、操作提示有不同显示区域 | 状态信息容易与内容竞争；提示文案代替了明确的控件反馈 | 保存状态固定在折叠按钮之后；选中对象由画布/轨道标识；长期任务用可返回入口，短反馈用轻提示；说明进入悬浮提示 |
| L10 / P1 | 功能继续插件化扩展，但布局仍容易随功能模块追加局部面板和入口 | 功能增加时可能再次形成第二套 Inspector 或重复菜单 | 宿主拥有工作区、布局和选择状态；插件提供能力和任务结果，进入现有任务入口与属性区；不新增并行侧栏 |

L08、L10 包含对继续开发的结构性风险判断，不代表已经复现了新的窗口闪烁或插件重启故障。插件生命周期实测仍以 [v12.7 隔离记录](Plugin-Lifecycle-v12.7-2026-10-09.md) 和 v13 回归为准。

## 3. 统一工作台结构

视频工作区采用下面一套结构。右侧所有功能共用一个属性面板，底边停在时间线上方；轨道横跨整个窗口。

```text
┌ 图标  文件 编辑 视图 帮助 插件 设置               主题  最小化 最大化 关闭 ┐
│                       图片工具  录制与视频  素材                 导出 │
├ 折叠 已保存         录屏 导入                 缩放 居中 ┬ 属性栏标题 ┤
│ 项目素材（可收起） │                                    │ 画面 片段 │
│ 搜索 / 导入       │             视频预览               │ 声音 字幕 │
│ 当前项目文件       │                                    │ 对应内容  │
│                   │             播放控制               │ 固定操作  │
├────────────────── 可拖动分隔线 ──────────────────────────────────┤
│ 撤销 / 剪辑操作 / 音频字幕入口                              轨道缩放 │
│ 时间标尺                                                        │
│ 视频                                                            │
│ 旁白 / 音乐 / 字幕                                                │
└─────────────────────────────────────────────────────────────────┘
```

### 不同层级各负责什么

| 层级 | 放置内容 | 交互规则 |
|---|---|---|
| 全局 | 文件、编辑、视图、帮助、插件、设置；主题；工作区切换 | 标题菜单与窗口按钮基线对齐；三个工作区相对整个窗口居中 |
| 当前文档 / 项目 | 保存状态、图片文档标签、截图或录屏、打开或导入、导出 | 工作区切换后保留各自文档、视图和未保存状态；素材库不显示无对应任务的全局导出按钮 |
| 当前对象 | 裁剪、描边、选中视频或音频片段、当前字幕 | 先有选择，再呈现相关属性；无选择显示相应空状态 |
| 视图 | 预览缩放、居中、时间线缩放、面板收起 | 预览缩放不改变导出分辨率；轨道缩放不改变片段时长 |
| 后台任务 | 录制、识别、生成、导出 | 面板隐藏后仍能看到任务并返回；录制允许直接结束；失败信息与重试入口留在任务所在位置 |

图标用于截图、打开、缩放、分割等已有清楚形象的命令，并提供悬浮提示和键盘名称。标签名称、布局选项、主要任务按钮保留必要文字，避免用户猜测。

### 保留的既定要求

- 沿用现有深浅主题、冷色强调色和 SVG 应用图标；输入与输出区域不加发光描边。
- 顶部仅保留应用图标；文件等菜单在最顶端；设置和插件继续使用独立窗口。
- 图片、录制与视频、素材居中；保存状态在折叠按钮后；缩放和居中与折叠按钮同一横向基线。视频页不恢复此前要求去除的项目名与操作提示行。
- 目录以文件夹图标和路径显示；点击图标选择目录，点击路径进入临时编辑。
- 属性面板左侧始终有分隔线；音频、字幕、视频和画面共用同一宿主。
- 轨道高度有上限；空间不足时隐藏视频缩略图并允许轨道容器滚动。
- 拼图宫格严格对齐；选图标注在预览中；照片缩放和位置调整直接在格内完成；添加入口在底部缩略图末尾。

## 4. 三个工作区的调整

### 图片工具

左侧只放工具；中央显示当前图片；右侧显示当前工具的参数。普通图片不再同时出现底部文档缩略图。

- 截图完成后直接进入当前工作区，选用框选、画笔、文字等工具时右侧切到对应参数。
- 裁剪进入原图边角手柄；比例在右侧直接选择，应用与取消保持可见。
- OCR 和多模态识图在工具栏中进入，结果留在右侧，可校对、复制；不因开始识别弹出新编辑窗口。
- 多模态补充问题只在多模态任务中出现，模型设置作为轻量入口打开现有设置窗。
- 拼图切到专用源图缩略条；布局、排列、显示方式和比例采用图示或分段选项，背景为颜色选择器。
- 普通图片多文档使用顶部标签；原型仅提供一个演示文档，正式实现需要补齐标签溢出与关闭行为。

### 录制与视频

增加可收起的“项目素材”栏，范围仅为当前项目用到或待添加的文件，和全局“素材库”区分。中央预览，右侧属性，底部轨道。

右侧四页：

1. **画面**：整个项目的尺寸、比例、背景、边距；高级圆角和阴影折叠。
2. **片段**：跟随轨道选择。视频显示时间、速度、裁剪、鼠标跟踪；音频显示时间、音量、淡入淡出。
3. **声音**：导入、用途、录音设备、输入电平、录制或结束。没有删除素材列表。
4. **字幕**：AI 生成 / 导入 / 新增；当前字幕文字和时间；整份列表与全局样式可展开。选择轨道字幕会同步到这里。

播放控制归预览区；分割、删除、撤销归轨道工具栏。入出点数值移入片段属性，给轨道留出实际编辑空间。原有快捷键继续由设置管理。

### 素材库

保留现有搜索、分类和预览能力，调整空间与下一步动作。

- 左侧按图片、视频、声音、项目分类；目录入口保持图标加路径。
- 中部支持缩略图网格和详细列表，搜索靠近素材内容。
- 右侧有限宽预览、关键文件信息；主按钮按类型决定接入位置。
- 选中预览，双击或点击主按钮进入编辑；回到素材时保留筛选与选择。
- 正式接入时，音频“添加到当前项目”应使用当前播放头位置，图片“打开”应激活对应文档；文件丢失需原位说明并提供重新定位。

## 5. 尺寸、密度与适配规则

以下数值是本次 Panzo 设计建议，原型以 CSS px 演示，对应原生 100% 缩放时的 DIP；它们不是行业认证要求。

| 区域 | 常规窗口 | 紧凑窗口 / 约束 |
|---|---|---|
| 顶层 | 标题菜单 32；工作区 44；上下文栏 40 | 三层高度稳定，长名称截断后悬浮展示 |
| 图片工具栏 | 44 宽；主要命令 32 × 32 | 不靠缩小点击区域换空间 |
| 属性栏 | 默认 304；可拖至 264—420 | ≤1150 宽默认 284；内容滚动，固定操作不参与滚动 |
| 项目素材 | 默认 212；≤1150 时 180 | ≤1000 自动收起，按钮可临时展开为覆盖式素材栏 |
| 时间线 | 900 高窗口默认 282 | ≤760 高时默认 230；拖动范围 150 至窗口高的 55% |
| 视频轨道 | 常规 62 高；紧凑窗口 48 | 时间线低于 200 时素材条 32，隐藏预览 |
| 其他轨道 | 常规 38；紧凑 32 | 轨道不足时滚动容器；不继续把每行压成细线 |
| 留白 | 面板边距 16；分组 14—16；相关字段 6—10 | 紧凑时内边距 12；高级内容折叠，不取消组间关系 |

建议正式最小客户区为 960 × 720 DIP。原型覆盖 1440 × 900 和 960 × 720；实际 DPI、系统文字放大和标题栏非客户区仍需原生复核。已有的系统辅助功能偏好继续有效，不直接把原型的 CSS 高度照搬为固定物理像素。

## 6. 交互与反馈

- 悬浮提示延迟出现；离开、开始拖动或打开菜单后立即收起。
- 控件颜色过渡约 100 ms；按下、拖动、裁剪即时跟手。布局改变不添加位移动画。
- 遵循系统减少动画偏好；键盘焦点使用实体标记。
- 调整面板宽度和时间线高度时，保存选择与播放位置，不重建任务。
- 图片及预览缩放支持 Ctrl＋滚轮；视图平移后可一键居中适配。
- 输入数据在应用前校验；数值需要预设时采用可输入的预设选择器。原型并非所有数值都接入业务。
- 导入、字幕生成、录制和导出都有空闲、运行、完成、失败、取消状态；本原型重点演示正常流程与插件停用状态，完整失败重试状态留待原生阶段验收。
- 当前用户的草稿、时间线选择和未保存状态应有独立身份，不能因切换工作区而错用另一工作区的撤销或保存状态。

## 7. 原生架构落点与实施次序

HTML 仅用于评审；正式界面继续复用现有 Rust / Windows 原生架构。不要同时保留新旧两套路由。

| 层 | 现有落点 | 实施边界 |
|---|---|---|
| 统一外壳 | workspace.rs、workspace_ui.rs、editor_titlebar.rs | 菜单、工作区、上下文栏的唯一布局入口；统一尺寸 token |
| 图片工作区 | image_workspace.rs、workspace_image_tools.rs、collage_workspace.rs | 工具选择驱动 Inspector；文档标签与拼图源图条分别按任务出现 |
| 视频布局 | editor_layout.rs、editor_navigation.rs、editor_chrome.rs | 单一预览 / Inspector 分隔；新增可收起项目素材栏；统一窄窗口策略 |
| 时间线 | editor_timeline.rs、editor_transaction.rs | 删除重复参数行；轨道命令与选中对象路由；沿用事务及撤销模型 |
| 媒体任务 | media_panel.rs、media_settings.rs、media_plugin_runtime.rs | 重新组织内容，保留固定主操作和现有插件执行边界 |
| 素材库 | capture_history.rs | 保留搜索和预览数据源，重排容器及类型化接入动作 |
| 通用控件 | editor_ui.rs、editor_widgets.rs、workspace_form.rs | 复用主题、提示、滚动、表单验证；避免每页另写一套控件 |
| 插件 | plugin_manager.rs、plugin_runtime.rs、plugin_ui.rs | 继续按插件隔离执行；布局由宿主控制，插件停用不清除已生成素材 |

插件的 UI 扩展契约建议描述“命令身份、目标对象、参数、任务状态”，由宿主决定放在哪里；这是后续扩展方案，不声称现有插件协议已支持任意第三方 UI 注入。

### 实施顺序

1. **统一布局契约**：尺寸 token、全局 / 文档 / 选择 / 视图状态、三层顶部、左右分隔与时间线规则。先接通现有页面，删除被取代的布局分支。
2. **视频工作流**：项目素材、片段属性、声音与字幕重排；把入出点移出轨道。复用现有业务命令、撤销和任务状态，不另造一份工程模型。
3. **图片与素材**：图片上下文工具、单一文档导航、拼图专用缩略条、素材预览与接入；完善空白、缺失文件和无选择状态。
4. **成品验收**：真实工程回归、缩窄与放大、键盘 / 输入法 / DPI、后台任务和插件热卸载；同时复查渲染性能。只有这一阶段通过才能称原生改造完成。

### 验收门槛

- 画面、片段、声音、字幕只有一个 Inspector 宿主，分隔线始终存在，轨道保持全宽。
- 保存状态与折叠按钮同排；右侧缩放 / 居中同排；标题菜单与窗口控制垂直对齐。
- 原生最小窗口下录制结束、字幕应用和取消始终可达；缩小轨道容器不把轨道压扁。
- 截图 → 标注 → OCR / 多模态 → 复制 / 导出能在一个工作区完成。
- 视频 → 音频导入 / 录制 → 字幕生成或添加 → 校对 → 导出闭环通过。
- 删除、分割、裁剪和属性调整进入原有撤销链；切换工作区不串状态。
- 插件卸载或停用按既有任务占用规则处理，其他插件任务及主进程保持运行，已生成内容保留。
- 通过 Win11、多 DPI 和真实媒体回归；原型浏览器检查不能替代这些验收。
