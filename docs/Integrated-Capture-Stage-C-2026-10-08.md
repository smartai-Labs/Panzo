# 第三阶段：录屏演示与视频导入

日期：2026-10-08。对应集成方案 C 阶段。候选程序：`target/integrated-stage-c/release/panzo.exe`。

## 使用入口

- 首页仍是功能菜单。「导入媒体」可打开图片或导入本地 MP4。视频导入显示进度，可从右上角设置取消；完成后直接进入编辑器。
- 录制前，右上角设置提供「普通录屏预设」「演示录屏预设」「录制设置」「录音设备与电平」。两个预设分别记忆最近参数。
- 录制设置支持 30/60 FPS、0/3/5/10 秒倒计时、鼠标显示、连续跟随/点击聚焦、1–3 倍缩放和 80–1000 毫秒响应时间。
- 录音设置可独立开启系统声音、麦克风，选择设备，检测 3 秒峰值电平。默认均关闭；电平检测不保存声音。
- 录制时显示置顶悬浮条：暂停/继续、跟随开关、停止、有效录制时长、系统/麦克风电平。主窗口最小化，悬浮条从捕获中排除。若系统无法排除悬浮条，则显示失败信息并保留主窗口控制。
- 快捷键：`Ctrl+Shift+R` 停止，`Ctrl+Shift+Space` 暂停/继续，`Ctrl+Shift+Z` 切换跟随缩放。快捷键冲突时仍可使用悬浮条/托盘。
- 编辑器左上角菜单 →「鼠标跟随、声音与帧截图」：修改整段跟随或指定素材区间，独立启停手工镜头，调节三个来源的音量/静音，截取当前合成画面。截图继续使用现有标注、复制、保存与贴图功能。
- 导出面板 →「范围 / 声音 / 质量」：起止时间使用剪辑后的时间线，终点留空且起点为 0 时导出完整视频。MP4 可带声音，质量选清晰/均衡/小体积；GIF 始终无声音，保留 10/15/20/25/30 FPS 与尺寸预设。

## 行为约定

连续跟随依据鼠标移动，不要求点击。中央安全区减少小幅抖动，视口限制在捕获区域内；鼠标离开区域后保持约 800 毫秒，再回全景。开关边界从该时刻开始平滑过渡，快速连续切换保持连续，不改写此前画面。

录制时的开关区间保存为原始素材时间。暂停同时移除视频、鼠标事件、声音和开关记录中的暂停时间。录后裁剪、分割、删除、变速通过统一素材映射，保持效果和声音对应。整段跟随设置会清除已有区间；指定区间仅覆盖该范围。手工镜头开启时优先于自动跟随；原有「应用/旁路镜头效果」仍控制全部镜头效果。

外部 MP4 的画面、声音导入为独立 `.panzo` 工程，不改动原文件。其画面内鼠标已烧录，没有可编辑鼠标事件，自动跟随入口禁用；裁剪、分割、速度、手工镜头、背景与导出仍可使用。中途改变视频尺寸的文件会给出不支持提示。

录音保留独立系统声/麦克风轨；导入视频声音单列一轨。每轨 0–200% 音量，混音峰值限制在有效范围。预览与导出使用相同的剪辑映射和音量。当前变速通过重采样处理，会改变音高。录音设备中断会停止录制、保存已完成内容并提示，不自动换设备。

## 实现与数据

工作台配置升级到 schema 6，兼容读取 1–5。旧工程没有自动跟随策略时保留原镜头轨语义；新字段覆盖源时间自动镜头策略、手工镜头开关和音量。设置修改进入已有撤销/重做和原子保存流程。

新增 `camera_policy`、`recording_time`、`recording_control`，共享预览/导出的评估器。音频采用 WASAPI，共享模式，系统回环和麦克风各自线程；工程资产采用 48 kHz 双声道 PCM16，以便独立混音和剪辑。每轨约 11.5 MB/分钟，工程体积大于最终 MP4。

音频设备的 QPC 包时间戳按 100 纳秒单位映射到视频首帧基准；暂停区间按同一时钟裁掉。[Microsoft 的 GetBuffer 文档](https://learn.microsoft.com/en-us/windows/win32/api/audioclient/nf-audioclient-iaudiocaptureclient-getbuffer)说明这一时间戳单位。MP4 导出使用 Media Foundation AAC 编码，并修正多音视频轨 fragmented MP4 的解码时间与数据偏移；无需额外安装编码软件。[AAC 编码器文档](https://learn.microsoft.com/en-us/windows/win32/medfound/aac-encoder)列出了支持的格式参数。

导入在工程库 `.panzo-imports` 的独立暂存目录中执行，可取消；只有完整工程才改名发布。原视频只读。音轨清单只接受固定内部路径。GIF/静音导出不打开不需要的音轨。

## 本机验证

- 标准验证：格式检查、全工作区测试、严格 Clippy、运行环境/编码器/视频转换探针，日志 `.tmp/stage-c-verify.log`。
- 246 项自动测试通过，25 项需要专用环境或显式输入的测试默认跳过。新增验证覆盖连续跟随、边界、快速开关、手工优先、素材时间映射、暂停边界、PCM 补零/变速/音量、预设分别记忆。
- 合成音视频：3 秒、90 帧、440 Hz 测试音的 MP4 写入、规范化和再解码通过。报告 `.tmp/stage-c-audio-01/aac-proof.json`。
- 视频导入：带声 MP4 导入、裁剪、两倍速、音量减半、撤销/重做/保存重开、0.6 秒片段导出并再解码通过；18 帧，音频时长误差小于 100 毫秒；取消清理、原文件不变。报告 `.tmp/stage-c-import-01/import-export-proof.json`。
- 实际区域录屏：只录制测试程序生成的图片，30 FPS，暂停 650 毫秒，验证有效计时冻结、视频时间戳连续、开关区间按素材时间保存；最终 46 帧、约 1.5175 秒。报告 `.tmp/stage-c-native-01/pause-proof.json`。系统回环初始化成功，音频设备枚举成功；该项未采集用户麦克风声音。
- 第一阶段区域捕获和 30/60 FPS MP4、15/25 FPS GIF 导出回归通过：`.tmp/stage-c-regression-a.log`。第二阶段截图编辑、贴图和重启恢复通过：`.tmp/stage-c-regression-b.log`。20 次真实编辑器往返通过：`.tmp/stage-c-navigation.log`。
- 最终严格 Clippy 通过：`.tmp/stage-c-final-clippy.log`。Release 构建通过，源码身份校验一致；第二阶段空闲主窗口已正常退出，第三阶段程序成功启动并响应。构建记录：`target/integrated-stage-c/release/candidate-build.json`，运行 PID 记录：`.tmp/stage-c-running-pid.txt`。

## 尚需设备和长时验收

本次完成可运行的 C 阶段候选，未把以下项目记为通过：不同物理麦克风和声卡的长时间双声源同步、设备拔插/睡眠恢复矩阵、跨 GPU、混合 DPI 全矩阵、各种外部 MP4 编码/旋转元数据兼容性、长视频性能及真人连续跟随舒适度。当前跟随支持固定区域内的鼠标轨迹，离开区域回全景；没有推断外部视频鼠标位置。

声音资产与录中策略在正常结束时发布；异常断电后的音轨与开关恢复还需专门加固，不能把已有视频恢复测试当作新增音频恢复保证。系统/麦克风输入默认关闭，长录制前可先用电平检测确认设备。
