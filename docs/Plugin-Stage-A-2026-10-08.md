# 插件第一阶段与统一工作区 · 2026-10-08

本阶段交付可安装的独立图片插件，以及主窗口中的功能管理。精简版 / 全功能版的自动组合发布仍需后续拆包；当前主程序仍包含 OCR、录屏、视频编辑等既有功能。

## 启动与使用

双击 `target/plugin-workspace/release/panzo.exe`。主窗口提供「图片工具」「录制与视频」「素材库」「设置」四个常驻标签。切换标签保留图片标注与撤销记录、识别结果、视频修改和播放位置；截图后先回到图片区，再选择 OCR 或多模态识图。

1. 设置 → 功能与插件管理 → 从文件安装。
2. 选择 `dist/plugins/panzo-image-filters-0.1.0-windows-x64.panzoplugin`。
3. 检查名称、版本、来源说明和校验值，点击「信任此来源并安装」。本仓库示例提供灰度、反色两项操作。
4. 图片工具 → 截图或打开图片 → 插件… → 选择操作 → 运行插件。
5. 完成后在图片下拉列表选择新图片。当前原图保持选中，原图及撤销记录保留；输出也自动保存到素材库对应的 `Screenshots` 目录。

识别、滤镜处理和设置均在功能区中完成。选择文件、桌面选区和必要的未保存确认仍使用系统窗口；只有明确执行贴图时创建桌面置顶窗口。

## 已实现的范围

| 功能 | 本阶段行为 |
| --- | --- |
| 内置功能启停 | 离线 OCR、多模态识图、拼图与批处理；状态长期保存，入口及任务提交检查状态 |
| 外部插件 | 独立编译的原生可执行程序，使用版本化 JSON 协议；主程序不链接图片滤镜实现 |
| 安装与更新 | 本地 `.panzoplugin` 文件；检查协议、架构、ID、PE 类型和 SHA-256；校验成功才替换登记 |
| 版本回退 | 更新后保留上一版本，回退前检查文件完整性 |
| 停用 | 阻止新任务，已提交任务继续完成 |
| 卸载 | 本实例任务完成后允许卸载；保留用户素材、输出和识图配置 |
| 后台运行 | 独立进程；取消、超时或宿主退出时清理工作进程；结果绑定原图片 ID 和版本 |
| 配置保存 | 插件文件和登记位于 `%LOCALAPPDATA%\Panzo\Plugins`；多模态密钥继续使用现有本机加密配置 |

插件包是 UTF-8 JSON 容器，包含清单与 Base64 编码的单个 EXE。第一版没有解压路径和安装脚本，也没有依赖下载、模型资源包或 DLL 依赖部署。协议和开发方法见 [插件开发说明](Plugin-Development.md)。

本阶段原生插件以当前用户权限运行，安装界面明确展示这一点。进程隔离用于避免插件错误拖垮工作区，不提供安全沙箱；作者字段是声明，校验值只能发现文件变化，不能证明发布者身份。仅应安装信任来源的原生包。

## 验证与边界

常规回归 275 项通过、0 失败，另有 32 项按条件忽略；独立插件进程和真实工作区两项专项验证通过。严格 Clippy、格式检查和差异空白检查通过；真实桌面回归使用隔离素材库和插件目录，不修改用户插件配置。原生窗口证据位于 [工作区验收](acceptance/plugin-stage-a-20261008/workspace-review.json)，构建身份、发布插件包及检查范围见 [验证记录](acceptance/plugin-stage-a-20261008/validation.json)。发布候选已启动，窗口标题为「Panzo · 图片工具」。

覆盖：独立进程灰度/反色处理、安装与重载、启停持久化、更新与回退、损坏/不兼容包拒绝、运行中禁止更新卸载、文件被修改的检测、坏登记文件不被静默重置；主窗口覆盖安装确认、打开插件面板后换图再运行会使用当前图片、提交插件处理、跨标签保留工作、图片 A 的 OCR 结果不进入 B、人工校对文字不被滤镜任务覆盖、卸载后图片和磁盘输出保留。

当前桌面验收通过宿主消息循环调用实际控件和业务逻辑，另有真实窗口截图；尚未完成完整的鼠标/键盘易用性、多 DPI 和多显示器矩阵。外部插件任务数管理目前限于本应用实例，不支持多个 Panzo 实例协同管理同一插件；多实例应在重启后读取更新后的状态。

外部图片插件当前限制为最多 4,194,304 像素、60 秒处理时限、32 MiB 可执行程序、48 MiB 包。长截图或 4K 图片超过上限会明确报错，原图不受影响；内置截图、OCR 与导出沿用各自已有规则。

第一轮只开放图片输入 / 图片输出操作，尚无第三方自定义界面、插件网络权限代理、签名验证、应用内在线目录、跨版本兼容范围或 GitHub 自动发布。内置功能停用不会缩小当前安装包。下一阶段应把识别/批处理逐项迁为独立包，再以同一个宿主生成基础包和预装官方插件的完整包。
