# 自定义快捷键 · v10

启动：`target/desktop-v10/release/panzo.exe`。入口为「设置 → 快捷键」，或「帮助 → 查看快捷键」。

## 使用

- 67 项功能统一管理：截图、录制、贴图、工作区、保存与撤销、识图、拼图、标注、图片变换、视频播放、逐帧、分割和导出等。
- 点击按键框后按下组合键；Esc 取消录入。右侧 × 清除，重置图标恢复单项默认。
- 支持按功能分类筛选，可滚动浏览；底部保存操作固定显示。关闭设置保留草稿，同时退出按键录入状态。
- 「恢复全部默认」和「撤销未保存修改」先更新草稿；点击「保存并生效」才改变实际绑定。
- 截图、录制、贴图和显示主窗口等后台功能可以选择「应用内」或「全局」。图片与视频编辑命令只在对应工作区响应。
- 文字输入保留原生复制、撤销和光标导航；Esc、Enter、Tab、Windows 组合键及控件导航属于固定界面操作。鼠标拖动、滚轮等手势保留。

## 默认绑定

默认仅注册两个全局快捷键，避开原先全局占用的常见 Ctrl+Shift 组合：

| 功能 | 默认快捷键 | 范围 |
| --- | --- | --- |
| 区域截图 | Ctrl+Alt+Shift+F9 | 全局 |
| 区域录屏 / 停止录制 | Ctrl+Alt+Shift+F10 | 全局 |
| 暂停 / 继续录制 | Ctrl+Shift+Space | 应用内，可改为全局 |
| 剪贴板贴图 | Ctrl+Shift+P | 应用内，可改为全局 |
| 打开快捷键设置 | Ctrl+Alt+K | 应用内 |
| 设置 | Ctrl+, | 应用内 |
| 图片 / 视频 / 素材工作区 | Ctrl+Alt+1 / 2 / 3 | 应用内 |
| 保存 / 撤销 / 重做 | Ctrl+S / Ctrl+Z / Ctrl+Y | 应用内 |
| 打开图片 / 拼图 / 识别 | Ctrl+O / Ctrl+Shift+J / Ctrl+Shift+O | 图片工具 |
| 快速保存到截图历史 | Ctrl+Shift+S | 图片工具 |
| 选择 / 裁剪 / 文字 / 马赛克 | V / C / T / M | 图片工具 |
| 图片缩放与适应 | Ctrl+= / Ctrl+- / Ctrl+0 / Ctrl+1 | 图片工具 |
| GIF 播放 / 暂停 | Ctrl+Space | 图片工具 |
| 视频播放 / 分割 / 起点 | Space / B / Home | 视频工具 |
| 逐帧 / 片段边界 / 跳转 | 左右方向键 / Ctrl+方向键 / Shift+方向键 | 视频工具 |
| 视频导出 | Ctrl+E | 视频工具 |

其余功能可自行绑定。默认组合降低全局占用数量，不能保证在每台电脑上都空闲；Windows 注册失败会明确提示，而不会抢占已有绑定。

## 保存和冲突处理

快捷键独立保存到 `%LOCALAPPDATA%\Panzo\shortcuts.json`，不随工程、主题切换或应用重启丢失。采用原子写入，不包含 API Key。

- 精确匹配 Ctrl / Alt / Shift，避免 Ctrl+Shift+S 被误当作 Ctrl+S。
- 检查应用内重复组合、系统保留组合、全局键是否合法，以及 Windows 实际占用。
- 修改全局绑定时先尝试注册新增组合，成功写入后才释放旧组合。任何新增注册或保存失败都会撤回新增注册，保留原配置及仍有效的旧按键；交换已注册组合可复用注册。
- 清除全局组合立即释放对应注册。程序退出时释放全部注册。
- 启动时若已有软件占用某个全局组合，显示具体失败项，其余功能仍可通过界面操作。
- 图片、视频的旧硬编码功能键已接入统一绑定。输入控件和正在进行的鼠标调整优先；在设置窗口录入现有全局组合不会执行其功能。
- 托盘和主要菜单读取当前配置显示提示，旧的固定快捷键提示已移除。
