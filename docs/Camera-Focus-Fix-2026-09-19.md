# 镜头聚焦修正 — 2026-09-19

候选：`dist/Panzo-RE-MVP-camera-focus-fix-20260919/panzo.exe`。

## 行为与实现

- 镜头现在插值裁剪视口范围，再反算倍率：`scale = 1 / ((1-t)/from.scale + t/to.scale)`。中心使用相同缓动进度，避免旧算法同时线性改变中心与倍率造成目标先反向移动再返回。起止时间、端点和缓动函数保持原定义，预览 / 导出共用核心逻辑。
- 自动镜头在相同倍率下，对不足当前视口 2.5% 的中心移动保持原焦点。距离相对于保留的焦点计算，因此连续小位移可以累计触发一次有效平移；后续点击仍延长停留时间。
- 旧工程加载与恢复自动初稿时清理细小自动 Pan，维护后续片段的连续起点；手动、锁定、用户修改片段及其入口状态不变。编辑器和直接预览 / 导出采用相同结果。原始保存状态仍用于并发保存校验，自动初稿保留；只有显式保存才写回清理结果。
- 光标可见性允许归一化坐标 1e-12 的边界舍入误差，避免精确角落在缩放中因约 1e-18 的负值瞬间隐藏；真实越界仍隐藏。

边缘目标继续采用稳定的贴边缩放，避免露出原视频范围外区域，鼠标不一定严格居中。自动镜头仍依据点击规划，不是逐帧跟随鼠标。旧工程重新打开即可使用修正，已导出的视频需要重新导出。低清时间线缩略图与此前界面修改保留。
