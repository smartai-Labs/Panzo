# 录制器与编辑器 UI 修订 — 2026-09-19

本轮已修改真实 Win32/GDI 界面和 D3D11 光标合成代码，并提供独立可运行候选。原来的原型页面保留。

程序：`dist/Panzo-RE-MVP-ui-polish-20260919/panzo.exe`。直接双击，无需安装。

## 已落地的调整

- 录制器改为紧凑的“新录制”工作区：来源切换、来源详情、录制按钮、最近工程按顺序排列。录制中使用明确的红色停止按钮和计时，工程目录与诊断收进更多菜单。
- 编辑器顶部只保留项目名、保存状态及操作。移除“本地工程 / 非破坏性编辑”、固定“原始画质”和常驻技术状态；错误仍会显示。
- 片段的开始、结束、倍率移入右侧属性栏，仅选中相应对象时显示。视频使用“素材入点 / 素材出点”，镜头使用“开始 / 结束 / 倍率”。打开工程时不默认选中镜头。
- 属性栏不再因窗口高度跳变而消失。短窗口可滚动，Tab 聚焦时自动显示对应控件；面板外控件不接受鼠标命中。图片标签下没有不可见色块命中区。
- 统一微软雅黑 UI、文本尺寸、按钮圆角和间距；图标与文字作为一个整体居中。普通按钮和选中标签采用中性配色，主操作使用蓝色。缩短工具栏和默认时间线高度，预览留白随可用高度调整。
- 鼠标在普通按钮上保持箭头，在文本、裁边、播放头、拖动区域和分隔条上显示相应系统指针。短片段的左右裁剪命中选择最近边缘，命中宽度按 DPI 缩放。
- 合成光标改为完整箭头轮廓，包含箭杆、深色描边和抗锯齿，尖端保持事件热点。预览与导出共用同一实现。
- 拖动滑杆、键盘和数值输入共用范围：边距 0–25%、圆角 0–源画面短边的 10%、阴影 0–100%。时间线适应全部时隐藏无意义的整条深色滚动滑块。

## 拖动模糊的处理

旧链路在拖动时把画面降到最长边 960 像素，缓存就绪后进一步使用 640 像素、1.5 Mbps 视频；放大到编辑器预览区时文字和边缘会变糊。

新链路保留源尺寸，后台短 GOP 缓存使用录屏码率策略，不复用旧低分辨率缓存。精确定位、播放、导出仍读取源素材。新目录为 `cache/scrub-v2-native`，单工程缓存预算仍为 512 MiB；超过预算或准备失败时继续读原素材。缓存是有损 H.264，保留尺寸不等于逐像素无损，因此界面不标注“原始画质”。

最终探针同时断言拖动解码帧未缩小。1440p 缓存实际解码为 **2560×1440**，见 [解码记录](acceptance/ui-polish-20260919/final-proxy-decode.txt)。60 秒样本缓存为 42,971,956 字节，准备约 61.2 秒；这个耗时来自本机样本，不代表其他素材。

## 保留的边界

1. 原尺寸预览比旧小图缓存消耗更多解码时间、磁盘和准备时间。初期构建冷态 P95 曾为 177.781 ms，超出目标；完整日志仍保留。最终单轮冷态通过不能抹去波动风险，也不能外推 4K / 高复杂度素材。未完成 30 分钟素材的整份原尺寸缓存准备或长时间资源耐久测试。
2. 桌面工具当前报 `failed to launch codex app-server: program not found`，没有完成真实鼠标手感、IME、跨显示器 DPI 和完整录制到导出的人工流程验收。几何与离屏检查不代替这些项目。
3. 原有偶发代理时间戳映射问题不凭本轮未复现关闭。音频、跨 GPU 兼容性等原有范围边界保持不变。
