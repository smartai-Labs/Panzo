# 托盘菜单统一 · v12.4

启动 [Panzo v12.4](../target/desktop-v12.4/release/panzo.exe)。保存当前工作并分别从托盘退出旧实例，再运行新版。检查时后台同时存在 `desktop-v11` 和 `desktop-v12.1`，旧进程不会自动变成新版本；本次未关闭这些进程或修改其中的工作。

## 本次调整

- 托盘菜单按截图、录屏、贴图、窗口操作分组，以细分隔线区分；“退出 Panzo”独立放在底部。
- 菜单标题与快捷键分开保存和绘制，快捷键统一在右侧对齐。预留固定间距和勾选标记位置，长标题不再与快捷键挤在一起；继续显示用户自定义的快捷键。
- 使用应用统一的常规字重中文菜单字体、SVG 图标、深浅主题、圆角菜单边框和悬浮样式。“关闭到托盘”显示勾选状态，录音设备入口使用麦克风图标。
- 保留原有菜单命令、隐藏 / 显示窗口行为及退出时的保存流程；无障碍菜单名称包含快捷键信息。

## 验证

- Windows 库回归：230 项通过，42 项按条件忽略；真实托盘菜单回归额外通过。

- 快捷键列覆盖 96 / 120 / 144 / 192 DPI，长标题、不同长度快捷键和勾选标记互不覆盖。
- 在隔离的真实工作区宿主中隐藏主窗口，分别打开深浅主题的真实托盘菜单并取消；确认窗口仍保持隐藏、托盘偏好不变。
- 隔离应用开启“关闭到托盘”后，通过原有退出命令正常结束。测试未启动录制、未打开用户文档，仅在测试线程隔离第三方输入法。
