# 多模态识图 · 2026-10-08

## 使用

打开 [多模态识图版](../target/multimodal-ocr/release/panzo.exe)，进入首页「图片工具」→「多模态识图设置」。

1. 填写支持视觉输入的 OpenAI 兼容服务地址、模型名称和自己的 API Key。地址可以是服务提供的 API 基础地址（如 `https://api.example.com/v1`），也可以是完整的 `/chat/completions` 地址。模型名称使用服务商的准确标识。
2. 选择默认使用「多模态识图」或「离线 OCR」，设置 10–300 秒的请求超时，点击「保存配置」。
3. 可点击「图片工具」→「测试多模态连接」。测试只向配置的模型发送应用生成的小色块，不读取屏幕；这也是一次模型请求，服务商可能计费。
4. 首页「文字识图」可截取所需区域；导入图片或截图编辑器中的「文字识图」、桌面贴图右键菜单也使用同一入口。
5. 选择「多模态识图」，再选择提取文字、提取表格、描述图片或自定义提问。填写补充要求后点击「发送识图」。发送前显示目标服务及模型。
6. 后台处理时可以取消；结果在应用内编辑、校对和复制。离线 OCR 保留原有语言选择和语言管理功能。

未安装 Windows OCR 语言包也可以使用在线识图。多模态模式需要模型自身支持图片；仅支持文字的模型不能替代视觉模型。当前支持 Chat Completions 的图片消息协议，不支持仅提供原生 Gemini / Anthropic 或 Responses 接口的地址，也不支持需要查询参数或特殊鉴权头的接口。

## 配置与密钥

设置独立保存在 `%LOCALAPPDATA%/Panzo/vision.json`，与工程、截图历史和主题设置分开。退出、重启或更换本项目的候选程序后仍会读取同一设置文件。

API Key 使用 Windows DPAPI 按当前用户加密后保存；文件中不保存明文 Key。再次打开设置时，Key 输入框保持空白且使用密码样式；留空表示保留原 Key，输入新值表示替换。选择「删除已存密钥」会删除保存的密钥并恢复默认离线模式。更换服务地址时需重新填写 Key 或删除旧 Key，避免把旧服务的凭据传给新地址。

远程地址要求 HTTPS，本机 `localhost` / 回环地址可用 HTTP。不会跟随 HTTP 重定向，不在错误提示中回显服务返回的原始内容、请求头或 Key，不自动重试可能已经计费的请求。截图只在用户选择在线模式并点击「发送识图」后上传；保存设置不会上传图片。

上传的是当前选区或图片编辑结果，已完成的遮挡会体现在上传图片中。使用无损 PNG，保留原始尺寸，透明部分合成白色；最长边 8192 像素、最多 1600 万像素、PNG 不超过 12 MB，超出时提示缩小选区，不悄悄降低文字分辨率。

## 验证与边界

工作区 266 项测试通过，30 项专项测试按原配置跳过；原生配置及跨进程读取检查另行执行并通过。格式、严格 Clippy 和差异空白检查通过。

- 新增接口测试：实际 HTTP 请求使用用户选择的模型、Bearer Key、中文提示词及 PNG 图片；从保存的加密配置重新加载后发起请求。
- 鉴权失败、限流、重定向、响应过大、错误 JSON、空结果、输出截断、请求超时和取消均有对应处理与回归检查。
- 原生配置窗口验证：密码样式、已保存 Key 不回填、留空保留、配置更新和删除；另起一个测试进程验证配置及 Key 可读取解密。
- 界面截图仅含测试数据，真实用户设置未修改。截图与测试结果见 `docs/acceptance/multimodal-vision-20261008/`。
- 接口联调使用本机模拟服务和虚构 Key。尚未使用用户的真实服务 Key 验证供应商端识别质量、账户权限或费用；在设置后运行「测试多模态连接」可验证自己的配置。

联网模型仍可能误读或补全，识别提示要求不猜测模糊文字，结果需要校对。此次新增可选识别方式，不将模拟接口返回的文字当作真实模型准确率测试。

## 实现与参考

`vision.rs` 负责图片编码、HTTP 和响应；`vision_settings.rs` 负责配置与 DPAPI；`vision_ui.rs` 接入设置、测试及识图任务。现有 `image_tasks` 继续承载可取消的结果窗口，`editor_dialog` 增加密码字段样式。

API 图片消息参照 [OpenAI Chat Completions API](https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create)。密钥保护使用 [Windows CryptProtectData](https://learn.microsoft.com/en-us/windows/win32/api/dpapi/nf-dpapi-cryptprotectdata)。网络使用系统证书验证及系统代理，不要求用户额外安装软件。
