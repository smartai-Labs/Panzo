# Panzo macOS 风格 UI Foundation 报告

> 历史报告：后续真实窗口复验再次发现文字溢出、时间尺信息重叠、固定像素和图标质量问题。本报告的视觉完成结论已由 [UI 重构第一阶段报告](V0.2-UI-Refactor-Slice-1-Report.md) 撤回；仅保留当时的实现与性能记录。

执行日期：2026-09-02（Asia/Shanghai）

## 阶段结论

Panzo 已完成 macOS 风格 UI 的第二轮可运行修正。第一轮虽然通过架构和自动化检查，但用户真实窗口视觉验收未通过：字体过小且呈调试工具感、可见文案仍为英文，并且 Editor 播放会闪动。本轮针对这三项反馈完成了实现级修正。

本轮已通过架构、布局、窗口生命周期、功能回归、导出一致性和性能门槛。由于当前桌面捕获接口连续返回 `0x80004002（不支持此接口）`，自动视觉截图仍未能取得；第二轮字体密度与视觉观感需要用户在真实窗口中复验，不能仅凭自动化结果宣告视觉验收完成。

## 已交付

- `editor_ui` 模块集中定义 macOS Dark Palette、布局尺寸、Button Role、Interaction State、圆角 Surface、Typography 和原生窗口 Chrome。
- 默认 GDI 小字体已替换为缓存的 `Microsoft YaHei UI` ClearType 字体，并区分 Caption、Body、Button、Heading、Title 五个层级。
- Recorder 与 Editor 的窗口标题、状态、按钮、检查器、时间线和文件选择器已中文化；自动化 CLI 输出保持英文以兼容验收解析。
- Editor 使用 Command Bar、Preview Well、Inspector、Timeline 四区布局，最小窗口尺寸为 1040×760。
- 用户反馈 Camera/Timing 操作与时间线距离过远后，缩放、焦点、起止时间已迁移到 Camera Track 下方的上下文工具条；Inspector 保留片段状态卡和 Appearance 属性。
- Timeline 增加独立 Header、缩放控制、圆角轨道、Manual/Edited 顶部标识、Selected 边框和左右修剪手柄。
- Editor 与 Recorder 均支持 Hover、Pressed、Disabled 反馈和 Hand Cursor。
- Recorder 与 Editor 共用 GDI 矢量图标，不再依赖 Unicode 箭头字形；悬停 550 ms 显示中文 Tooltip。Tab/Shift+Tab 跳过禁用控件并循环导航，Enter/Space 激活当前焦点，焦点环与原生窗口标题同步显示唯一的控件可读名称。
- Windows 11 标题栏启用深色模式和系统圆角，不伪造 macOS 交通灯窗口控件。
- Recorder 主窗口使用相同色板、圆角状态卡和按钮组件。
- 正式入口拆分为 Windows GUI 子系统的 `panzo.exe` 与控制台子系统的 `panzo-cli.exe`：前者无参数启动 Recorder、默认工程库为 `%USERPROFILE%/Videos/Panzo` 且不创建控制台窗口；后者承载 Preflight、技术探针和自动验收。GUI 启动失败通过原生对话框显示。
- 播放刷新保持每帧只更新 Preview、Timeline 最多每 100 ms 更新；Inspector 与 Command Bar 不逐帧重绘。
- 修复播放闪动：此前小脏区直接在窗口 DC 上依次清背景、绘制 Preview Well、清黑底、写入视频帧，用户可看到中间状态；现在所有脏区先在兼容位图中完整合成，再单次 `BitBlt` 上屏，同时取消视频写入前的额外黑底清除。
- 修复随机定位 SelectionMismatch：Source Reader 仍先执行快速直跳；若硬件路径从目标 PTS 之后返回，则自动从前 30 帧预滚，并按需扩大到流起点，最终只接受索引指定的精确帧。用户报告的 `TimeTick(23759628)` 已用同一项目精确复现并通过。
- 修复时间线点击定位卡顿：精确预滚从 UI 线程中的单次同步循环改为计时器驱动的增量任务，每轮最多读取 4 帧；目标前样本不再执行 BGRA 拷贝，新点击可以替换未完成定位。
- 修复 Camera Segment 长度调整导致窗口未响应：拖动开始立即暂停播放，鼠标重绘按 16 ms 合并，只遍历可见的点击和片段；松手后的编辑状态提交改走增量预览，不再同步调用 `render_current()`。
- 新增时间线播放头 Scrub：Ruler、Click Track、空白 Camera Track 和蓝色播放头均可拖动；拖动请求按 50 ms 合并并显示最近近似帧，松手后重新执行严格精确定位。硬件返回的非索引近似时间戳只用于拖动预览，不会污染精确播放状态。
- 修复定位期间空格键失效：播放改为显式的延迟意图状态，空格和播放按钮可立即请求或取消“定位完成后播放”；精确帧就绪后自动进入播放。
- 修复 Recorder 无法二次打开 Editor：窗口类注册现在把 `ERROR_CLASS_ALREADY_EXISTS` 视为同一进程内的合法复用；新增 `preview-reopen-smoke`，连续两次创建和关闭 Editor 均通过。

## 性能复验

同一 2560×1440 工程，5 秒播放：

| 版本 | Rendered Frames | 约合帧率 | 说明 |
|---|---:|---:|---|
| UI Foundation 初版整窗重画 | 149 | 29.8 FPS | 圆角组件随视频逐帧重画 |
| 局部刷新修正后 | 175 | 35.0 FPS | 每帧只刷新 Preview |
| 中文 Typography + 脏区双缓冲（Release） | 168 | 33.6 FPS | 每帧只刷新 Preview；脏区单次提交 |

当前修正版 5 秒 Release 烟测渲染 173 帧，平均合成约 19.5 ms，最大约 84.1 ms；背景解码、背景纹理上传和输出纹理分配均为 1 次。Paused 2 秒仍只渲染和绘制首帧 1 次。Camera Segment 修剪 Release 探针中，UI 提交约 8.2 ms，随后通过计时器完成精确预览。
