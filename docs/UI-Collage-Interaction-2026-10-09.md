# 拼图属性与预览交互 · v6

启动：`target/desktop-v6/release/panzo.exe`。v5 保留，本轮未覆盖旧程序。

## 本轮调整

- 排版布局：两图、三图、四宫格、九宫格四张原生示意卡，直接点击切换，选中项有配色和勾选标记。
- 排列方向、照片显示、单格比例：分段按钮，不再藏在下拉菜单里。四/九宫格禁用方向；贴合模式自动计算比例，并禁用固定比例选择。
- 背景：色块和 HEX 值，点击打开统一颜色选择器，支持调色及手动 HEX。背景保持不透明，颜色面板中透明度禁用，避免提供无效参数。
- 长边上限、间距：保留可编辑下拉框，既能选择预设，也能输入任意有效数值。
- 移除“当前照片”下拉框以及照片缩放、左右/上下位置字段。在预览点击照片，使用橙红色边框和编号标记实际可见照片范围；选框随画布缩放、平移变化。
- 三种显示方式均支持直接拖动照片、以鼠标所在位置为中心滚轮缩放（1–3 倍），双击恢复该照片的初始位置和缩放。触及图片边界时会约束位置；满格且未放大的照片需要先放大才有可平移空间。
- Ctrl + 滚轮缩放整个画布，Ctrl + 拖动平移整个画布；底部适应窗口、缩放与 100% 按钮保留。拼图不显示无用的播放按钮。
- 底部缩略图排序和照片替换、移除、前后移动、重置按钮保留；功能按钮仍有悬浮提示。

## 绘制方式

拖动与滚轮操作使用后台生成的照片缓存，在预览原有的缓冲绘制中完成画面与选框更新。拖动期间不反复加载源文件或生成完整分辨率拼图；结束操作后后台更新完整结果。预览和输出共享照片变换计算，生成前等待当前完整结果就绪。选框及编号只属于界面，不写入图片。

缓存代理图长边最多 1024 px；停止操作后的预览恢复完整结果的缩略图。快速操作时与最终结果可能有正常的重采样清晰度差异，输出仍使用原始文件。
