# 固定灰色标题栏

上一版透明标题栏依赖 DWM 背景，在 Windows 10 上会随激活状态变为黑色。本次统一由应用以不透明像素绘制整个顶部：深色主题固定为 `#2B2B2B`，浅色主题为 `#EEEDE9`。录制页与编辑页使用同一实现，窗口按钮默认没有独立背景块。

应用按系统标题按钮区域绘制最小化、最大化/还原、关闭图标，并同步悬停反馈；保留 DWM 命中检测和系统窗口命令。左侧菜单、右侧设置位置和已有功能保持不变，顶部不显示工程名称。

涉及 `editor_ui.rs`、`editor_titlebar.rs`、`preview_window.rs` 和 `recorder_window.rs`。

验证覆盖深浅两种主题、编辑器普通/最大化/还原、录制页，以及各状态下失焦→激活→再次失焦的像素检查：背景必须等于指定灰色，包括三个窗口按钮区域。检查了按钮图形可见性、原生命中码、系统最小化/还原命令和两种菜单的打开/关闭。最大化截图的屏幕外隐藏边框不计入可见标题栏采样。

图像与测试日志保存在 [fixed-caption-20260926](acceptance/fixed-caption-20260926)。此处程序化窗口消息验证不等同于实际鼠标点击验收。

工作区测试 223 项通过、19 项环境相关测试默认忽略；上述深浅主题的原生窗口专项检查另行运行并通过。格式检查和 Clippy（`-D warnings`）通过。Release 启动检查正常创建窗口并退出，媒体错误为 0，构建源代码指纹一致。
