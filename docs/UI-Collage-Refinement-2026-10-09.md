# 拼图属性细化 · v7

启动：`target/desktop-v7/release/panzo.exe`。

## 变更

1. 添加图片：移到下方缩略图末尾，使用与缩略图完全相同的尺寸和间隔，只显示加号。空列表时在首位，增删照片后自动移动。最多九张照片，满额时保留并禁用添加格；删除照片后重新启用。
2. 单格比例：修正原图贴合模式禁用比例按钮的问题。六个按钮始终可用，包括新增的“自动”。固定比例在原图贴合模式下会同步切换到铺满裁剪；保留留白模式下则继续保留留白。选择“自动”恢复原图贴合。当前模式和比例的选中状态同步更新。
3. 去除常驻提示：属性区及预览底部不再显示“点击照片选中”“拖动定位”“滚轮缩放”等教学提示；正常状态属性区留空。保留实际图片尺寸、画布缩放信息、错误与缺少照片等必要状态，以及按钮悬浮提示。
4. 属性面板：宽度从 352 增至 384 DIP，左右内边距增至 24 DIP；分组之间留白加大，分段按钮高度增至 36 DIP；比例按两行、每行三个排列。长边、间距、背景各行间隔增至 50 DIP，照片操作按钮之间也增加间距。较矮窗口可滚动属性区，缩略图及添加格固定在下方。

## 验证

- Windows 模块自动化测试：214 通过，37 项专用交互测试保持 ignored，0 失败。
- 使用原生按钮点击，从自动贴合模式逐一选择五种固定比例，测量预览照片边框的实际宽高比；同时验证“自动”恢复原始照片比例。
- 验证添加格在空列表、四张、九张以及删除照片后的尺寸和位置。
- 原生发布版回归已通过：三种显示方式的缩放/拖动/重置、选择边框、布局方向、HEX 背景颜色、画布缩放及生成 1376 px 可编辑图片。已检查深浅色截图。
- 像素测量在窗口重绘完成后通过 PrintWindow 获取，仅检查测试进程；测量期间尺寸变化会判为无效，避免把窗口大小变化误判为照片变换。
