## 三轮完整任务

任务说明给评审者，不提示按钮位置。使用有静止、滚动、点击和跨区移动的五分钟操作素材 F04；不能用持续棋盘动画替代真实编辑任务。三轮可使用不同工程或不同评审者。

1. 不打开命令行，选择显示器或应用窗口，确认实际尺寸与无音频提示，完成录制。
2. 停止后进入正确工程；裁去头尾，在中间分割并删除一段，确认空隙闭合。
3. 添加一个镜头，在时间线移动并调整长度，在画布调整焦点，输入倍率；旁路后恢复效果。
4. 选择背景图片，调整边距 / 圆角 / 阴影 / 光标；撤销和重做上述不同类型操作。
5. 保存，关闭并重新打开，确认修改保留。尝试未保存关闭时的保存 / 不保存 / 取消。
6. 导出原始尺寸与 1080p；导出过程中修改工程，确认该输出仍使用开始时的快照。
7. 测试取消、已有同名文件保护；成功后打开视频和所在文件夹。

## 视觉与键鼠

- 录制器、选中视频、选中镜头、属性输入、导出设置 / 进度 / 结果：分别截图。
- 1024×720、1440×900 DIP 和最大化；100% / 125% / 150% / 200% DPI。物理屏幕容纳不下的组合注明不可运行，另测工作区自适应折叠，不填 Pass。
- 检查中文字体、长项目名、数值、按钮、标尺、状态行无覆盖或溢出；错误摘要与可复制详情入口均可见。
- 普通按钮释放即解除按下状态，移出 / 捕获丢失 / Alt+Tab 均正确；焦点环与开关状态不同。
- Tab 顺序；输入法输入中文；数值输入中的空格 / Delete 不触发全局命令；Esc 取消输入或拖动，不退出工程。
- 镜头 / 视频边缘一次拖动只产生一次 Undo；Esc 与捕获丢失恢复原范围；Alt 暂停吸附。
- 长时间线的滚轮、中键、滚动条、缩放锚点、恢复跟随与自动平移；小窗口下保存 / 导出仍可达。
- 播放、拖动、窗口调整大小时录制测试窗口的动态画面，检查黑帧、闪烁、旧帧倒灌。

用户对正式界面的视觉确认单独记录。布局单元测试通过或原型确认不自动填入视觉 Pass。

## 性能采样

严格沿用 Recording-Editing-Acceptance-Plan.md 的 RE-PERF-01～08 门槛，不临时调宽。

F01～F05 各三轮十秒往返、反转与首尾跳转；定位 / 松手 / 播放每类累计至少 100 样本，按素材及冷热状态分别汇总 P50 / P95 / P99 / 最大值与失败数。实际输入时间与软件 Present、可见画面分别计时，不用人工秒表估算毫秒指标。

F03 使用可识别不同帧验证每个连续两秒窗口的有效更新；连续五分钟拖动记录任务 / 缓存峰值及淘汰。实际画面不可见、采样数不足或仪器未接通时保持 NotRun。
