# Panzo RE-MVP 候选包

双击同目录的 **panzo.exe** 打开录制器。panzo-cli.exe 是诊断工具，不是日常启动入口。

最新为 9 月 19 日编辑体验优化版：增加可视化裁剪框、比例锁定、画布比例及自定义尺寸、逐帧与片段边界定位、吸附参考线、布局记忆和未保存编辑恢复。速度与裁剪分组可折叠，属性栏边缘的可见控件保持可点；向前拖动减少无用的原分辨率帧复制。见 [本轮说明及验证](docs/Editor-Workflow-2026-09-19.md)。

当前是本机回归用候选版，不是整体通过的正式发布。请先阅读 [验收报告](Acceptance-Report.md) 和 [已知问题](Known-Issues.md)，操作说明见 [使用说明](使用说明.md)。

- 已接入录制、视频裁剪 / 分割 / 删除、镜头 / 背景 / 光标编辑、保存重开和 MP4 导出。
- 9 月 19 日更新：紧凑录制器、统一中文字体和按钮、按操作切换鼠标形状；去掉常驻技术说明，片段参数移入可滚动侧栏，拖动预览保留源尺寸。见 [本轮修改和验证](docs/UI-Polish-2026-09-19.md)。
- 自绘控件已增加中文辅助技术名称、焦点、播放位置与片段选择接口；修复暂停编辑器初次打开时控件树未发布的问题。实现与实机工具限制见 [续开发记录](docs/RE-MVP-Accessibility-Report.md)。
- 无音频；其他 GPU 兼容性与自动镜头自然度没有通过声明。
- 历史长工程代理时间戳映射错误尚未全部关闭；本轮修复了另一个已复现的解码器异常时间戳定位问题。完整性能验收仍有缺口，本包仍为候选版。
- 新编辑数据保存后会升级工程格式。先复制整个 .panzo 工程目录，再使用候选版编辑；不要用旧应用回写新版工程。
- build-manifest.json 记录本包的 EXE Hash 和 Windows 子系统标记；releaseAccepted=false 表示没有整体放行。
- 附带报告链接的 JSON 证据，不附带用户录屏、鼠标轨迹或背景素材。JSON 中的原始日志 / 工程绝对路径指向开发机，相关大文件不在本包内；历史文档链接也不代表历史材料完整随包分发。
- 源工程不会被候选安装包覆盖；本包无需安装，也没有自动更新旧程序。

实际界面、键鼠、DPI 与完整任务的待验收项见 [桌面复验清单](docs/RE-MVP-Desktop-Review.md)。
