# Panzo V0.2 GPU Preview 升级报告

执行日期：2026-09-02（Asia/Shanghai）

## 阶段结论

Editor 的交互预览已从“D3D11 合成 → Staging Texture → GPU Readback → CPU BGRA Copy → GDI `StretchDIBits`”切换为绑定子窗口的 DXGI Flip Swap Chain。播放、精确定位、Scrub、镜头修改和修剪预览直接渲染到 Swap Chain Back Buffer，再交由 DWM 合成；父窗口的工具栏、检查器和时间线重绘不再改写视频区域。

Render Hash Probe 与 Export 仍使用原有可回读合成入口，因此所见即所得的确定性验证没有被删除。Swap Chain 初始化失败时保留明确的 CPU/GDI 兼容回退，Smoke 报告不会把回退误记为 GPU Direct。

## 实现边界

- `D3d11Compositor` 新增可复用 `GpuPreviewPresenter`，使用双缓冲 `DXGI_SWAP_EFFECT_FLIP_DISCARD` 和 BGRA8 Back Buffer。
- Preview 的解码/求值阶段与最终输出阶段分离为 `PreparedPreviewFrame`；Editor 直接 Present，探针按需执行 CPU 合成和 Hash。
- Preview 子窗口使用 `WS_CLIPCHILDREN` 与父窗口 UI 隔离，窗口缩放时只移动呈现面，不重建原生分辨率 Back Buffer。
- Cursor、背景、画布样式和镜头焦点十字在同一 Pixel Shader Pass 中合成，避免视频与覆盖层分步上屏。
- Compositor 分别统计 CPU Readback 和 GPU Presentation；Editor Smoke 同时输出 Direct 状态与两类计数。
- `verify-editor-mvp.ps1` 将 GPU Direct、Present 非零、CPU Readback 为零、离屏 Output Texture 分配为零设为硬性回归条件。
