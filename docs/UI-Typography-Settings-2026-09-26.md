# 字体与设置整理

本轮只调整已有功能的样式与入口，没有增加新的编辑参数。

## 字体

共用微软雅黑 UI 字体，正文由 13 DIP/400 调为 14 DIP/500，按钮及菜单项为 14 DIP/600，分组标题为 15 DIP/600，辅助文字由 12 DIP 调为 13 DIP。菜单测量使用与绘制一致的字样，录制页、编辑器、内联输入及弹窗继承公共字体。长时间码采用 13 DIP 辅助样式，避免高 DPI 窄窗口挤占播放按钮空间。

## 现有入口整理

| 原设置内容 | 当前入口 |
| --- | --- |
| 主题与诊断 | 右侧设置菜单 |
| 打开文件位置 | 左侧主菜单 |
| 属性栏展开/收起 | 预览区右下角原有按钮 |
| 背景自定义颜色 | 画布属性 → 背景 → 自定义 |
| 背景图片 | 画布属性 → 图片模式 → 原有图片预览 |
| 边距、圆角、阴影 | 画布属性中原有滑杆和数值框 |
| 光标显示 | 原有显示光标开关 |
| 光标倍率 | 显示光标下方的光标大小，保留倍率范围及当前显隐状态 |
| 镜头启用、恢复自动镜头 | 时间线工具栏 |
| 镜头时间、倍率、焦点 X/Y | 选中镜头后的片段操作区参数按钮 |
| 视频入出点 | 选中视频后的片段操作区入出点按钮 |

移除设置中的重复弹窗入口及误导性的滑杆提示；圆角统一沿用属性栏的像素表达。视频、镜头参数按钮随选择状态出现并复用现有可用性检查；背景导入期间禁用颜色编辑。
