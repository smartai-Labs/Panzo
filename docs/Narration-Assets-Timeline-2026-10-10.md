# 实时旁白、素材删除与时间轴缩放 · 2026-10-10

## 行为

1. 录制旁白时，轨道上显示持续增长的临时片段和真实 PCM 采样波形，每 120 ms 轮询新增数据。关闭/隐藏声音属性页不影响实时轨道更新。停止并成功完成后一次性写入正式片段，支持撤销；取消、出错或面板销毁会清除临时预览。
2. 项目素材区的旁白与音乐提供右键“删除素材”、更多菜单“删除所选素材”和 Delete 键操作。仍被轨道片段引用的素材禁止删除，并提示先移除对应轨道片段。素材记录独立保存在工程内：删完轨道片段后素材仍留在左侧，保存重开也保留。之后可删除未使用素材，保留磁盘文件；支持撤销与重做。声音或字幕任务运行时先结束任务再删除，避免覆盖任务上下文。主视频作为当前工程基础仍处于使用中，删除项禁用。
3. 时间轴最小缩放扩展到“项目总时长占可用轨道宽度 50%”。按钮、滚轮及缩放滑杆使用同一范围，“适配项目”仍恢复铺满。点击尾部空白区域时定位限制在项目结尾；概览状态不显示无意义的水平滚动操作。
4. 声音面板“添加为”采用单行垂直居中的原生标签，和角色下拉框处于同一行中心。

## 实现

- 实时旁白只更新临时显示状态，不逐帧改动项目、撤销栈、素材列表或 GPU 视频画面。
- 每轮最多读取一秒 PCM，逐帧聚合为 100 ms 峰值桶；重复轮询不会重复采样，静音段为零。读取的是现有插件输出文件，不变更插件协议，已安装媒体插件仍兼容。
- 全局快捷键对素材列表的 Delete 让行，列表自身处理当前素材，防止误删时间轴中其他选中项。

新增素材元数据写入工程设置 schema 9，旧工程从已有轨道音频迁移素材记录。保存基线仍使用原始磁盘设置，保持旧工程草稿校验与撤销兼容。
