# Panzo 工作区 UI v2 · 交互设计稿

双击 `index.html`，无需安装依赖或联网。默认浅色；右上角切换深色。顶部明确标注设计预览，当前原生 EXE 尚未替换。

- 图片工具：截图按钮加入示例素材；可导入、拖入、粘贴本地图片。矩形/画笔与撤销可试用。
- OCR / 多模态：演示后台任务、取消、结果归属和手工校对；不执行真实识别，不发送图片。
- 录制与视频：录制前参数、鼠标跟随开关、停止后编辑、区内 MP4 / GIF 导出流程；不采集或编码。
- 素材库、插件和设置：筛选、导航、开关、插件清单预览、明暗主题。不会修改 Panzo 的真实插件、素材、API 配置。
- `Ctrl K` 搜索功能，`Ctrl O` 导入，`Ctrl V` 粘贴，`Ctrl Z` 撤销，`Esc` 收起面板或关闭必要的确认。

主题偏好使用浏览器 localStorage；其他内容仅保留在当前页面会话。请勿在原型输入真实密钥。原型不提供完整裁剪、马赛克、真实保存、视频剪辑或生产插件安装。

设计规范与原生改造顺序：[UI 重构规格](../../UI-Workspace-Redesign-2026-10-08.md)。

运行验证：`node scripts/test-workspace-v2-prototype.cjs`。脚本启动专用临时配置的无头 Chromium，不连接用户浏览器；证据写入 `docs/acceptance/workspace-v2-design`，通过后同步至本目录 `previews`。原型验证不能代替原生 EXE 验收。
