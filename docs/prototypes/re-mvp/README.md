# R0：Panzo 可交互界面原型

双击 [index.html](index.html)，使用本机 Chrome 或 Edge 打开。无需安装依赖、启动服务或联网。

这是设计评审原型，**不是新版 panzo.exe**。页面顶部始终标注“仅供评审”；模拟录制不访问屏幕，保存不写工程，导出不生成文件，刷新会清空修改。全程没有上传接口。

## 建议评审顺序

1. 先看“编辑器”：浅色工具区、独立深色预览区域，时间码与标尺分离，项目外观在右侧，镜头数值紧邻时间线。
2. 在标尺上按住拖动；松手后按空格播放/暂停。可拖动镜头主体和两端、在预览中拖动焦点；数值可直接输入。
3. 点击分割，选中视频片段后删除，使用撤销/重做恢复。调整背景、边距、圆角和阴影。
4. 点击右上“导出”，检查设置、模拟进度、取消与完成反馈。
5. 切换“录制器”，模拟开始/停止，确认录后进入编辑器的流程。
6. 可点“载入本地视频评审”，检查真实内容放在新界面中的效果。文件仅在当前页面读取，不会上传或改写。

## 当前边界

- 浏览器中的视频定位不是 Panzo 的 Media Foundation / DXGI 链路，不能用原型的流畅度判定正式程序性能。
- 示例视频轨道缩略图目前是布局占位，不是逐帧缩略图。镜头效果演示不等同生产版 source-anchored 剪辑/过渡算法；不复制原型模型替代 R3 的版本化模型。
- 图片替换和源视频载入是原型资源操作，不做工程持久化；载入新视频会重置示例编辑。图片多次替换不提供完整资产级撤销。
- 错误/恢复、全套DPI与键盘/无障碍状态仍需补充，不以这次测试宣称 R0 或 UI 最终通过。

## 自测

在项目根目录执行：

```powershell
node --test docs/prototypes/re-mvp/model.test.cjs
node scripts/test-r0-prototype.cjs
```

浏览器测试脚本只启动一个独立、无扩展的本地无头浏览器，使用专门的临时配置，不连接用户现有浏览器。结果和截图在 `docs/acceptance/RE-MVP/r0-prototype-*/`；临时浏览器配置位于 `.tmp/r0-browser-*`，不自动递归删除任何目录。

测试真实本地素材时可显式设置 `PANZO_R0_VIDEO` 指向一个 MP4；默认不会搜索或上传用户文件。正式程序基线使用 [measure-r0-baseline.ps1](../../../scripts/measure-r0-baseline.ps1)，不是本页的动画数据。
