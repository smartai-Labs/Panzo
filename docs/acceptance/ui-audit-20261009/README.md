# 绘制闪烁审查证据

本目录属于 2026-10-09 的问题筛查，记录修复前状态，不代表修复验收通过。

- audit-target.json：被审查二进制的哈希及源文件核对结果。
- drawing-audit.json：隔离测试配置、合成图片尺寸、采样位置及统计。
- drawing-samples.json：每个采样点的相对毫秒时间及 Windows COLORREF 值。
- drawing-before.png / drawing-after.png：合成图片绘制前后截图；静态截图本身不能呈现闪烁，需结合原始采样。
- drawing-probe.py：本次使用的诊断脚本，需要 Windows、Python 和 Pillow，从仓库根目录运行。它会启动自己的候选进程并临时置顶，使用独立的配置/合成图片，发送画笔消息、采样像素；结束时只关闭自己的进程。重复运行会更新本目录同名采样和截图，因此复验应先保留本次证据副本。

本次采样约 2.79 秒，共 280 次：217 次为画布底色，颜色切换 39 次。COLORREF 15657704 对应图像 RGB(232,234,238)，2105886 对应画布 RGB(30,34,32)。采样点不在画笔路径上。

这是中间清底状态的动态证据，不是帧率基准；采样次数不等于显示帧数。采样依赖当时的窗口几何、显示环境和候选界面，后续布局改变后需要相应调整定位。零次异常采样不能排除短于采样间隔的闪烁。
