# Panzo 一体化捕获：第二阶段实现与使用说明

日期：2026-10-08。对应 [整体方案](Panzo-Integrated-Capture-Plan-2026-10-08.md) 的 B 阶段：截图、标注、桌面贴图与本地历史。已实现本阶段核心流程并完成本机回归；混合 DPI 多显示器实机验收仍待补测。

## 启动

双击 [第二阶段候选程序](../target/integrated-stage-b/release/panzo.exe)。首页继续使用功能菜单。第一阶段候选保留在 `target/integrated-stage-a/release/`。

开发启动：`cargo run -p panzo-app --bin panzo`。本机 Cargo 未加入 PATH 时使用 `& "$env:USERPROFILE\.cargo\bin\cargo.exe" run -p panzo-app --bin panzo`。

截图、贴图和 GIF 编码均在应用内完成，无须另装截图软件或 FFmpeg。

## 本阶段功能

| 功能 | 当前行为 |
|---|---|
| 精确选区 | 悬停吸附可见顶层窗口；拖动矩形选区；拖动选区边缘调整尺寸，拖动内部移动；显示物理像素尺寸 |
| 快捷截图 | 支持当前显示器、整个虚拟桌面、上次区域；托盘提供 3 秒延时截图；选区工具条可直接复制、保存、贴图或切换录屏 |
| 像素取色 | 11 × 11 像素放大镜；HEX / RGB 复制 |
| 标注 | 矩形、椭圆、直线、箭头、画笔、荧光标记、中文多行文字、序号、马赛克、模糊、实色遮挡 |
| 编辑对象 | 选择、移动、Shift 拖动调整两端点图形、删除；可改颜色、线宽、字号和文字；撤销/重做 |
| 图片变换 | 裁剪、旋转、水平/垂直翻转、取消裁剪；变换可撤销；坐标反变换确保旋转后继续标注的位置正确 |
| 输出 | PNG / JPEG 另存为；快速保存截图历史；复制合成后的图片；PNG 保留透明，JPEG 用白底合成 |
| 桌面贴图 | 置顶、拖动、缩放、透明度、锁定、鼠标穿透、缩略/展开、旋转/翻转、全部显隐；支持原尺寸和显示尺寸复制 |
| 贴图编辑 | 右键“编辑此贴图”或 Space 打开同一份标注；编辑与贴图同步，不必生成新副本 |
| 恢复 | 最近关闭贴图恢复；跨进程重新启动后恢复图像、标注、位置、显示尺寸、透明度、锁定与显隐状态；屏幕外位置移回最近显示器工作区 |
| 历史管理 | 搜索最近 500 项截图/录屏工程；显示在用及最近关闭贴图；打开、恢复、复制、再次贴图、定位文件和清理最近关闭记录 |
| 托盘 | 默认关闭主窗口进入托盘；设置/托盘可切换此行为；显式退出沿用录屏收尾和工程保存，并检查尚未保存的图片编辑 |

截图编辑器保留独立原生窗口，主功能菜单不会因此加载视频编辑器。导出文件仅包含合成后的像素；可再次编辑的原图与标注保存在应用本地贴图恢复数据中。

## 操作

全局快捷键：

| 按键 | 操作 |
|---|---|
| Ctrl + Shift + S | 截图 |
| Ctrl + Shift + R | 选择录屏区域 / 停止录制 |
| Ctrl + Shift + P | 将剪贴板图片贴到桌面 |
| Ctrl + Shift + H | 全部贴图显示/隐藏 |
| Ctrl + Shift + I | 恢复全部贴图交互：显示、取消穿透和锁定、恢复不透明、移回屏幕内 |

如果快捷键被占用，主页会提示；同一功能仍可从菜单进入。穿透功能只有在托盘或恢复快捷键可用时才允许开启。重启后恢复贴图时会主动关闭鼠标穿透，避免找不到贴图。

截图选区内：Enter 进入标注，Ctrl+C 复制图片，S 快速保存，P 贴图，R 将选区用于录屏，Esc 取消。A 选择整个虚拟桌面，F 选择鼠标所在显示器，L 恢复上次区域。方向键移动选区，Shift+方向键调整尺寸。C 复制当前像素 HEX，Shift+C 复制 RGB。

标注窗口：先选工具，再拖动或点击图像。文字先在文本框输入，再点击图像放置。选择已有文字后修改文本框并点击“更新文字”；颜色、粗细、字号修改后点击“应用样式”。Ctrl+Z/Y 撤销/重做，Delete 删除所选对象，Ctrl+C 复制，Ctrl+S 快速保存，Ctrl+Shift+S 另存为。

贴图：滚轮缩放；Ctrl+滚轮调整透明度；双击切换缩略/展开；Space 编辑；右键提供保存、旋转、翻转、锁定、穿透、隐藏及关闭。主窗口“最近内容”打开统一历史窗口；“恢复全部贴图交互”也可从这里操作。

## 数据与资源

默认库：`%USERPROFILE%\Videos\Panzo`。

- `Screenshots/`：截图及快速保存结果。
- `.panzo-pins/session.json`：原子写入的贴图恢复索引；标注可编辑，撤销栈仅在当前进程内保留。
- `.panzo-pins/assets/`：贴图原始 PNG；本阶段最多 24 张同时在用、12 张最近关闭，原始像素合计 256 MB，恢复资源上限 512 MB。
- `.panzo-pins/last-region.json`：上次选区。

损坏的恢复索引会保留备份；无法读取的单张贴图记录保留供重试。历史窗口提供清理最近关闭记录，操作前确认，保留在用贴图和已保存截图。贴图隐藏状态也会保存。

## 当前边界与下一阶段

本阶段吸附对象为顶层窗口，尚未提供 Snipaste 的控件级识别；图片背景/阴影修饰、快捷键自定义和贴图分组仍属于后续增强，不能把本次交付描述成 Snipaste 全功能复刻。分组归 D 阶段，修正第一阶段说明中将其笼统归 B 的表述。

已实现物理像素坐标、负坐标桌面、窗口 DPI 变化布局及恢复位置约束；本机验证不能替代混合 DPI 多显示器拖动、插拔显示器和不同缩放比例的实机矩阵。干净系统安装、长时运行和多 GPU 也未作为本轮通过项。

下一阶段 C 聚焦录屏：连续平滑鼠标跟随、录中/时间区间缩放开关、暂停继续、系统声/麦克风、MP4 导入和区间导出。本阶段保留 A 阶段已实现的录前缩放开关与点击聚焦，不把它们标记为连续跟随。
