# 本机字体与透明文字编辑 · 2026-10-10

当前程序：`target/desktop-v14-fonts/release/panzo.exe`。双击根目录 `Start-Panzo.cmd` 启动。

SHA256：`0aca6c96e32eea325cfa31badc13d4ac2668c8868b14d3da19c034ffd0ddcc7d`。

## 实现

- 图片文字在图片上直接输入，输入框透明，保留原生文字选择、光标和输入法接入。拖动边缘移动，双击已有文字重新编辑；右侧内容与画布同步。
- 使用 RichEdit 文字服务绘制到图片背景的离屏表面，按不透明度合成。输入框下方是实际图像，而非单一背景色；颜色面板预览也同步编辑中的文字。
- DirectWrite 枚举本机已安装字体及可用字重。图片和字幕共用字体选择控件，可输入字体名称、选择字重、斜体、下划线和左中右对齐。字号、颜色、不透明度仍在对应属性区调整。
- 图片字号使用原图像素；字幕沿用视频高度百分比。字形测量取代按字符数量估算边界。图片渲染和字幕预览/导出均使用所选字体与样式。
- 字体样式写入图片标注和字幕工程设置，支持撤销与恢复。旧数据缺少新字段时使用默认值；字体缺失时保留原名称，显示缺失提示并回退到微软雅黑。
- 字幕字体样式作用于全局字幕，与现有原型的全局样式区一致；字幕底色开关独立于文字透明度。
