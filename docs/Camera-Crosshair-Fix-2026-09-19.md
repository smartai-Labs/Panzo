# 镜头十字全画面选点修正 — 2026-09-19

候选：`dist/Panzo-RE-MVP-camera-crosshair-20260919/panzo.exe`。

## 原因与修正

原实现把黄色十字的位置直接取自镜头裁剪中心。默认 1.6 倍时，为避免裁剪越界，中心只能位于原画面 31.25%～68.75% 范围；拖到边缘后选点丢失，十字返回受限区域。GPU 还会把十字一起套入圆角遮罩，导致角落标记被裁掉。

现在在镜头片段中独立保存可选的 `focus`，范围为原视频 0～1。拖动、焦点数值输入、居中、方向调整和倍率调整使用该位置，渲染镜头仍按边界约束计算裁剪中心。缺少此字段的旧工程保持原行为和 JSON Hash；已有工程无须转换，重新选点即可保留完整焦点。

GPU 和 GDI 使用相同焦点坐标映射，包含画面边距和当前镜头变换。GPU 十字在画面圆角合成后叠加，背景和圆角不再将它遮住。十字只在编辑预览中显示，导出仍使用无编辑标记的合成路径。

一次拖动对应一次撤销，Esc 取消恢复原焦点；相同裁剪中心内的两个不同选点也会正确记录为编辑。时间调整、倍率调整和保存重开均保留选点。先前稳定缩放、自动小平移抑制及低清时间线缩略图保持不变。
