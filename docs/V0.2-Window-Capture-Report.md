# Panzo V0.2 Window Capture 阶段报告

执行日期：2026-09-02（Asia/Shanghai）

## 阶段结论

Window Capture 已形成可运行闭环。Recorder 可以在主显示器和可见应用窗口之间选择捕获来源；窗口源继续使用 Windows Graphics Capture、独立输入轨道和硬件 H.264，不改变 Editor、Preview、Export 的后续读取方式。

## 已交付

- 枚举当前可见、未最小化的外部顶层窗口，过滤 Panzo 自身窗口和 DWM Cloaked Window。
- Recorder 增加“捕获来源”控件和原生来源菜单，录制进行中禁止切换。
- 新增 `window-list` 与 `window-record-probe` CLI，支持按唯一标题片段选择窗口。
- 捕获核心从主显示器硬编码升级为 `RecordingSource`；Monitor 与 Window 共用 WGC→D3D11→NV12→Hardware H.264 链路。
- Project Manifest 向后兼容增加 `kind=window`、`windowId`、`windowTitle`；旧 Monitor Project 无须迁移。
- Window Capture 接受任意宽高比；奇数宽高最多裁去最右或最下 1 像素，保证 NV12 编码尺寸合法。
- 每 100 ms 刷新窗口桌面原点；窗口移动后 Cursor/Click 使用递增 Geometry Revision 和新坐标。
- WGC 内容尺寸改变时拒绝混合分辨率录制，保留 Project 供启动恢复。
- 修复 WinRT Apartment 提前析构：所有 Capture Item、Session、Frame Pool 与 D3D 对象释放后才反初始化 WinRT，窗口录制进程不再在成功完成后发生 `0xC0000005`。

## 当前边界

- 录制中允许移动窗口，但暂不支持改变窗口内容尺寸；Resize 会明确失败并进入既有 Project 恢复流程。
- 最小化窗口不会出现在新选择列表中。已开始录制的窗口若被关闭，当前录制会失败并保留可恢复项目。
- 不同 GPU 物理机兼容性测试按产品决定继续保持 Deferred。
