# Panzo RE-MVP 候选使用说明

本版本用于本机验证，尚未完成真实 UI / 完整输入性能验收，不是已通过全部验收的正式发布版。它不录制音频；跨 GPU 兼容性和自动运镜自然度未纳入本轮结论。

操作说明已按 2026-09-26 工作区的单主窗口实现更新；具体候选程序以其构建和验收记录为准。

## 打开与录制

1. 在候选目录双击 **panzo.exe**。`panzo-cli.exe` 是诊断程序，会显示控制台，不是日常启动入口。
2. 选择主显示器或可见应用窗口，核对实际尺寸。录制使用捕获源的实际像素尺寸，默认目标 60 FPS；不是强制输出某个显示器支持的最大规格。
3. 点击录制。结束时点击停止，等待收尾完成；工程 Ready 后在同一主窗口进入编辑器。
4. 工程默认保存在用户的 `Videos\Panzo` 目录，每次录制是独立 `.panzo` 文件夹。原视频在 `media\screen.mp4`，请保留整个工程文件夹。

录制准备和编辑器共用一个主窗口。标题栏左侧为三横主菜单，包含“录制新视频”“打开工程”“继续最近工程”“保存”“导出”“打开文件位置”；设置齿轮位于原生最小化按钮左侧。顶部中间留空，不显示工程名称或应用名。“打开工程”选择已有工程中的 `project.json`。“继续最近工程”沿用已有入口，不提供多条历史记录；没有可继续的工程或已在该工程中时禁用。

在编辑器通过主菜单点击“录制新视频”会回到录制准备，不会立即开始录制，也不会退出应用。切换工程、回到录制准备或关闭主窗口前，未保存修改会询问保存 / 不保存 / 取消；取消或保存失败时保留当前工程。若导出尚未完成，离开工程会先询问是否取消导出。点击窗口关闭按钮才请求退出整个应用；文件选择器和确认对话框仍使用系统窗口。

## 界面主题

点击主窗口标题栏右侧、最小化按钮左边的齿轮，在设置菜单选择“浅色主题”或“深色主题”。选择立即生效并在下次启动保留，不改变视频画面或工程背景。没有打开工程也可以切换。浅色采用米白和暖灰，深色采用炭灰和米白。

主菜单与设置菜单共用面板底色、行高、文字、图标、悬停底色和轻分隔线，不显示白色外框；当前主题以选中标记表示。设置面板向左展开，与右侧齿轮对齐。

设置菜单只保留主题与诊断。打开文件位置在左侧主菜单；属性栏开关在预览区右下角。画布、光标参数在右侧“画布”属性中。选中镜头后，在时间线的片段操作区点击参数图标可输入镜头时间、倍率和焦点 X/Y；选中视频后，同一区域提供入出点编辑按钮。时间线工具栏的恢复图标沿用“恢复自动镜头初稿”操作，支持撤销。

编辑器的预览、属性和时间线采用三个紧凑的小圆角卡片。深色主题为深灰整体背景、较浅的卡片背景；时间线功能按钮和轨道区域底色一致。播放控制位于预览卡片底部。

## 基础剪辑

输入不符合范围时，数值不会应用，输入框附近会说明如何修改；按 Esc 可取消并保留原值。正常取消不会作为错误显示。左下角会明确说明未完成的操作；保存失败会持续提示“尚未保存”，请保留窗口并重新保存，其他编辑成功不会清除这条提醒。详细技术原因可在设置 → 诊断详情中查看。

编辑器工具按钮以图标为主，鼠标停留后显示名称与快捷键，移开即隐藏。标题栏左侧是主菜单，右侧依次是设置、原生最小化、最大化和关闭。标题栏空白处可拖动窗口，双击可最大化 / 还原；未保存修改仍在离开工程时询问处理方式。时间线工具区左侧依次是撤销、重做、分割、添加镜头、删除和镜头效果，右侧为缩放与适应全部。镜头图标的选中底色表示效果已启用；属性名称和数值仍直接显示。

- 单击标尺定位；按住标尺 / 播放头拖动，画面跟随，松手回到原视频精确帧。首次打开长工程可能在后台准备流畅预览代理，最终导出不使用代理。
- 空格播放 / 暂停。文本框内的空格不会触发全局播放；Tab 聚焦按钮后，Enter / Space 激活该按钮。
- 视频轨道主体用于选择；拖动左右边缘裁头尾。选中视频后可以打开入点 / 出点输入框，单位是**源视频秒数**。
- 在播放头按 **B** 分割；选中片段按 **Delete** 删除并闭合空隙。不能删除最后一段。本轮不支持重排、重复或添加外部视频。
- 视频轨道上的蓝色片段与镜头轨道是不同对象；Delete 删除当前选中对象。
- Tab / Shift+Tab 按布局顺序移动焦点，包含播放位置和视频 / 镜头片段；焦点进入片段时会选择它并将相应时间移入视野。焦点轮廓不是按钮一直按下。
- **Ctrl+Z / Ctrl+Y** 撤销 / 重做。一次拖动或连续滚轮调整提交一次撤销；**Esc** 取消当前手势，不关闭工程。
- 时间线的 **← / →** 或播放按钮两侧的逐帧按钮按 60 fps 输出帧定位；**Ctrl+← / →** 跳到前后片段边界，**Shift+← / →** 跳转 5 秒。聚焦参数控件时，方向键优先调整该参数。

## 时间线与镜头

时间线左侧显示“时间”和视频、镜头图标，不显示图标旁的“视频”“镜头”文字及未选择片段时的操作提示。选中片段后，上方仍显示可编辑的时间及镜头参数。

- Ctrl+滚轮缩放时间线；普通滚轮 / Shift+滚轮、水平滚动、中键拖动和底部滚动条用于平移。“适应全部”恢复跟随播放头。
- 拖动上下卡片之间的横向窄缝调整时间线高度，预览和属性卡片同步变化。最高约占窗口的 22%，小窗口保留可操作高度，并可向下收窄时间线。视频和镜头轨道同步分配空间。撤销 / 重做位于时间线顶部工具条；Esc 取消当前尺寸调整。
- 视频轨道使用固定 160 像素低清缩略图，按轨道高度缩放显示；首次打开时等待预览缓存就绪后逐步填充。调整高度或 DPI 不再重新生成高清缩略图。主视频预览与导出保持原有分辨率。
- 拖动预览与属性卡片之间的竖向窄缝调整宽度；Esc 放弃本次调整。小窗口中的属性栏可以滚动，播放条右端可收起或展开。属性宽度、显隐、时间线高度及速度 / 裁剪分组折叠状态在下次打开时恢复；受当前窗口可用空间约束。
- 镜头轨道附近可添加、删除、移动、修剪镜头；选择镜头后，在预览画布拖动焦点或用滚轮调整倍率。
- 黄色十字可选到视频四边和四角，松手后保留实际选中的位置。焦点与镜头裁剪中心分开保存，边缘缩放仍不露出原视频之外的区域；调整倍率、撤销重做和保存重开均保留焦点。十字仅用于编辑，不会进入导出视频。
- 选中视频片段或镜头后，在时间线工具条下、标尺上方调整参数：视频显示入点 / 出点，镜头显示开始 / 结束 / 倍率与居中焦点图标。点击数值框输入；Enter 应用、Esc 放弃。属性栏收起时仍可调整，设置菜单保留焦点 X/Y 的完整输入。
- 输入框未修改就退出不会产生编辑；输入非法值会保留文字并提示，不静默修改成其他数值。
- 调整片段或镜头边界时，默认在 6 DIP 内吸附播放头与相邻边界，显示黄色虚线参考；按住 Alt 暂时解除。按 Esc 放弃当前拖动。
- 新录制默认展示原始画面。镜头效果开关只旁路效果，不删除数据；恢复自动初稿是显式可撤销操作，会替换当前手工镜头，请谨慎使用。
- 开启自动镜头后，缩放保持稳定方向；相邻点击造成的移动不足当前视口 2.5% 时保持原焦点，累计移动明显后再平移。边缘点击采用贴边缩放，避免露出原视频之外的区域，鼠标不一定严格位于画面中心。
- 旧工程重新打开时应用同一修正，并清理未锁定、未手动修改的细小自动平移；若因此出现未保存标记，点击保存即可保留清理结果。手动镜头和锁定镜头保留；原视频不会重写。已导出的 MP4 需要重新导出才会应用修正。

## 视频速度

- 右侧属性栏用“画布 / 视频”标签切换。选择时间线上的视频片段会打开“视频”页；单独移动播放头不切换标签。直接点击“视频”标签时，优先编辑已选片段，没有选择则选中播放头所在片段。
- 播放速度支持 **0.25×–4×**，可拖动滑块、点击常用倍率，或点击数值输入，精度为 0.01×。Enter 应用，Esc 放弃；聚焦滑块后左右键以 0.05× 调整。圆形返回箭头恢复 1×。
- 面板显示所选范围的原始时长及调整后时长。速度仅影响选中的片段，后续片段自动前移或后移，镜头和光标随源画面同步；预览和导出使用同一速度。
- 片段边缘拖动仍是裁剪，不会改变播放速度。分割后的两段继承原速度；速度拖动可用一次撤销恢复，支持重做、保存与重开。

## 画面裁剪

选中时间线的视频片段，在右侧“视频”页找到“画面裁剪”。点击分组右侧裁剪图标进入预览调整：拖动八个边角手柄改变裁剪，拖动框内移动保留区域，框外暗化。锁形按钮保持当前宽高比例，四边滑块及数值与裁剪框同步。拖动中 Esc 取消这次手势，Enter 或再次点裁剪图标完成；播放、定位或切换对象会结束辅助视图。辅助框不会进入导出视频。

也可点击四边数值输入百分比，精度 0.1%；宽高至少各保留 5%。16:9、4:3、1:1、9:16 预设重新居中裁剪，返回箭头恢复完整画面。速度与画面裁剪分组的标题均可点击折叠，分组右侧快捷操作仍保留。

裁剪仅作用于所选片段，不改变时长或速度；分割后的两段继承裁剪。预览和导出保持裁后画面比例，等比居中放入当前输出画布，剩余区域显示所选背景。支持实时预览、一次拖动一次撤销、重做、Esc 取消、保存与重开。原视频保留不变。

## 外观、保存与导出

- 右侧“画布”标签包含背景、画面、光标和画布尺寸，作用于整个工程。画布可选原始、16:9、9:16、1:1；宽高框支持自定义，均为 64–8192 的偶数且总像素不超过 33,554,432。画布改变支持撤销、保存和导出。画面保持比例居中，沿用不额外放大裁后源像素的规则；大画布可能保留背景区域。点击“显示光标”下方的“光标大小”可调整倍率，范围为 0.25–4，保留当前显示/隐藏状态。
- 在“背景”分组右侧用纯色 / 图片图标切换模式，再选色块或点击下方图片预览选择 / 更换文件。纯色模式下点击色块下方“自定义”可输入十六进制颜色。图片按比例显示，悬浮时出现更换图标；更换背景可以撤销 / 重做。边距 / 圆角 / 阴影可直接拖动滑杆，点击右侧数值框输入；圆角框以原始画布像素显示。Tab 聚焦滑杆后，左右键也可调整。属性栏内容超出高度时，滚轮用于上下滚动。背景图片会复制到工程 `assets`，移走原图片不影响已导入工程。
- Ctrl+S 或主菜单中的“保存”显式保存；保存中可继续编辑，新修改不会被后台保存误标成已保存。关闭未保存工程时会询问保存 / 不保存 / 取消。
- 普通编辑窗口约每 2 秒检查一次未保存修改，在手势结束且没有保存 / 背景导入任务时后台写入恢复副本。意外关闭后重开会恢复最近成功写入的修改并提示；恢复可撤销。选择“不保存”正常关闭时会清理副本。尚未完成写入的最后几秒修改不保证恢复；恢复副本不替代手动保存。
- 选择主菜单中的“导出”，在同一主窗口的标题栏下打开导出面板。默认选择原始尺寸；设置了画布尺寸时显示“画布尺寸”。1080p 选项按自定义画布方向输出：横向不超过 1920×1080，竖向不超过 1080×1920，正方形不超过 1080×1080；小尺寸不放大。尚未自定义画布的旧工程保留原导出行为。
- 开始导出前，面板的尺寸与时长随当前编辑刷新。启动时先提交有效输入，再冻结完整编辑快照，包含尚未保存的修改；导出途中继续编辑不会改变本次参数和输出内容。
- 面板的“收起”或 Esc 只隐藏面板，不取消正在运行的任务；再次选择主菜单中的“导出”可查看进度。在面板点击“取消导出”才明确取消任务。切换到其他工程后，导出位置不会沿用上一工程的面板状态。
- 已存在的同名文件不会被覆盖。成功后通过左侧主菜单“打开文件位置”打开视频、所在位置或工程目录。

## 限制、异常与备份

- 这是无音频版本，暂不支持字幕、多轨或外部视频素材。
- 录制期间改变被捕获窗口尺寸或关闭它，会明确终止并保留可恢复工程；本轮不支持动态改尺寸录制。
- 保存会将 `edit\workbench.json` 升到 schema 5，以保存速度、画面裁剪和画布尺寸。schema 1–4 旧工程按原有尺寸打开；缺少速度 / 裁剪时默认 1× / 完整画面，旧构建不能回写新格式。
- 如果保存失败，不要直接强制关闭；窗口保留当前修改。可以在更多设置的诊断详情中按 Ctrl+C 复制错误。
- `cache\scrub-v3-native-bt709` 是新版预览缓存，保留源素材尺寸；旧缓存不再用于拖动预览。首次准备缓存可能较慢，单工程缓存预算为 512 MiB，超出时继续使用原素材。勿删除 `media`、`events`、`tracks` 或 `edit` 来清理缓存。
- 本轮仅在 Windows 10 19045 / RTX 4080 SUPER 主机实测；不据此宣称 Windows 11 或其他 GPU 已通过。
- 自绘控件已提供中文辅助技术名称和操作接口，但完整读屏、输入法及真实鼠标流程仍待验证，不能据此认定所有辅助工具均兼容。
- 已知长工程拖动偶发代理时间戳映射错误尚未关闭。候选用于检查新界面，建议只用工程副本；出现错误请保留诊断信息，不把后续偶然正常当作问题已解决。
