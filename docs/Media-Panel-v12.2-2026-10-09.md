# 声音与字幕面板调整 · v12.2

启动 [Panzo v12.2](../target/desktop-v12.2/release/panzo.exe)。保存当前工作并从托盘退出旧版后打开新版。现有媒体插件与 AI 字幕设置可继续使用。

## 使用变化

- 声音面板分为音频文件、旁白录制两组，移除重复的素材列表、剪切和删除工具栏。导入时可选择旁白或音乐；录制区提供设备选择、刷新、计时、电平和结束录音。
- 面板左侧增加贯穿高度的分隔线，与视频区区分；统一深浅主题、分组标题与留白，不给文字框添加亮边。
- 字幕面板保留手动添加、AI 自动生成、SRT 导入 / 导出、内容校对和字幕样式。选中轨道上的字幕后编辑内容。
- 音频与字幕在轨道中选择、拖动定位、拖动两端裁剪，使用共用工具栏或快捷键分割、删除，支持撤销。右键菜单提供分割、删除和属性 / 字幕编辑。
- 音量、淡入淡出、静音、用途及精确时间从音频轨道的右键“音频属性”调整，显示在独立属性区，不放在录音面板中。

## 设备问题

旧设备枚举返回“显示名称、设备 ID”，声音面板却把两者反向使用，导致列表显示端点编号，并可能把设备名称传给录音插件。

现在改为明确的 `AudioDevice { id, name, is_default }`。列表显示名称，录音请求使用 ID，默认项显示当前系统默认麦克风的名称。刷新按 ID 保留选择，设备移除时明确提示；无可用麦克风时禁用录音。原生录制设置也使用类型化设备字段。媒体处理仍调用独立插件，未改变插件协议。
