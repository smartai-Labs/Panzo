# 统一右侧属性面板 v12.6

2026-10-09。候选程序：`target/desktop-v12.6/release/panzo.exe`。已安装的媒体插件兼容，无须重装。

## 布局

右侧固定为同一个属性面板，顶部使用“画面 / 视频 / 声音 / 字幕”标签切换内容。左侧统一绘制竖向分隔线，可拖动调整宽度；整个侧栏底部与轨道上方的横向分隔线相接，拖动轨道高度时同步调整。轨道工具栏和所有轨道始终横跨整个工作台。

删除了主窗口为视频功能单独分配整高 440 DIP 侧栏的路径，删除打开声音面板时强制隐藏原属性面板、拉高轨道的逻辑，删除声音面板自己的标题、标签栏与独立竖线。图片工具和素材的表单布局保留。

## 实现与交互

- 编辑器 `ControlLayout` 是唯一的预览、侧栏、轨道布局来源，`inspector_host.rs` 在统一内容矩形内承载媒体插件页面或轨道属性表单。
- 声音、字幕页面作为编辑器的子控件接入；主窗口只负责路由打开请求，不再分配其宽高。
- 保留原尺寸记忆、折叠 / 恢复、滚动、键盘与辅助功能；显示媒体内容时，原画面 / 视频属性控件不接收点击或键盘操作。
- 切换到画面或视频只隐藏媒体页面，缓存、任务接收器仍保留。正在录音或处理任务时，声音与字幕之间的切换有明确提示，避免丢失当前任务操作入口。
- 音频属性也进入同一内容区；关闭后恢复画面 / 视频内容。插件协议和处理能力未变更。
