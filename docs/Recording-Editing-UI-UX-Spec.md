# 录制与基础编辑：UI/UX 重设计规范

版本：RE-MVP / 2026-09-26（更新主窗口、导航与导出约定）  
状态：单主窗口实现已接入；完整实机视觉、输入与辅助技术验收仍须独立完成  
上位计划：[PROJECT-PLAN.md](../PROJECT-PLAN.md)

## 1. 设计目标

目标是具有 macOS 创作应用的清晰层级、精致排版和克制控件的 Windows 应用。不是“深灰背景 + 圆角按钮”，也不是复制 Apple 品牌、系统窗口按钮或把中文换成图标就算完成。

保留当前浅色与深色两套主题，两者使用同一个设计体系、布局、字体、图标和控件状态规则；录制准备与编辑允许不同信息密度。不以模糊/透明特效优先于文本和视频清晰度。历史原型确认不代表当前原生窗口已通过完整视觉验收。

Apple 对字体层级与一致性的建议、图标/文字按钮和悬停提示规则可作设计参考；以下尺寸、配色和交互均为 Panzo 自身的待验证约束，不声称是 Apple 强制规范。参考：[Typography](https://developer.apple.com/design/human-interface-guidelines/typography?changes=_5)、[Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons?changes=latest_minor)。

## 2. 信息架构

```text
┌ ☰ 主菜单 ─────────── 留空 ────── 设置 ─ 原生窗口控制 ┐
│                                                  │
│               预览画布               │ 项目外观    │
│        选中镜头时直接显示焦点操纵框      │ 背景/光标   │
│                                     │ 可折叠属性  │
├────────── 播放/暂停 · 当前时间 / 总时长 ─────────────┤
│ 视频/镜头上下文命令                     时间线缩放 │
│ 时间标尺（只显示刻度）                              │
│ 视频轨道：缩略图与裁剪/分割结果                      │
│ 镜头轨道：缩放/移动片段；点击标记为可隐藏辅助         │
│ 选中对象属性：开始、结束、时长；镜头倍率/焦点入口      │
└ 简短操作反馈 ───────────────────── 后台任务状态 ┘
```

一次应用会话使用一个业务主窗口，在共享标题区下切换录制准备、录制状态和编辑内容。三横主菜单位于左侧，设置位于原生最小化按钮左侧，两者根据系统标题按钮实际边界垂直居中。中间留空，不显示工程名或应用名。录制新视频、打开工程、继续最近工程、保存、导出集中在主菜单，不可用操作置灰。原生预览子窗口、文件选择器及临时确认对话框不改变这一主窗口约定。

- 一个时间码主显示区，不在标题、标尺、状态行重复堆积当前时间。
- 标尺不承担错误、片段数量、保存状态或操作帮助；统计信息放诊断面板。
- 右侧负责项目级外观和光标，不常驻十几个镜头方向/增减按钮。
- 镜头命令与数值位于镜头轨道邻近上下文区；焦点优先在画布直接拖动，微调放次级弹出区和键盘。
- 视频片段与镜头片段样式/选择态不同。“删除镜头”不能删除视频；工具提示和撤销记录必须说明对象。
- 默认显示视频和镜头两个编辑层；点击标记可隐藏，不为无音频版本画伪音频轨道。
- Inspector 可折叠，Timeline 可调高度；极限尺寸时折叠次要区域，不通过缩小字体塞入所有控件。

## 3. 视觉与控件体系

### 3.1 初始设计 Token（R0 用原型确认）

所有布局单位为 DIP，DPI 变化后按实际字体重新测量，不直接套屏幕物理像素。

| 类别 | 初始约束 |
|---|---|
| 字体 | Windows 可用的系统 UI 字体，中文回退明确；正文/按钮不使用等宽字体；不打包未经许可的 Apple 字体 |
| 字号/行高 | 主体 13/20，辅助 12/18，分组标题 13/20 半粗，页面标题 16/24；时间码可用等宽数字 |
| 间距 | 4/8/12/16/24；面板内边距 16；同组 8；组间 16～24 |
| 控件 | 常规高度 32；图标 18～20，常规命中区至少 32×32；标题栏按钮为 28×28，与系统标题高度协调；小手柄提供更宽命中区 |
| 圆角 | 控件 6～8，面板 10～12；不把每一行都包成独立卡片 |
| 颜色 | 浅色 Window `#F3F2EE`、Surface `#FDFCF9`、Text `#272723`、Accent `#403E35`；深色 Window `#1C1C1A`、Surface `#262624`、Text `#EBEAE6`、Accent `#DDD9CF`；视频和镜头轨道使用低饱和灰绿与暖棕 |
| 边界 | 优先空白、轻分隔线和层级；减少深色描边与全屏相同重量矩形 |
| 强调 | 开始录制使用主色；保存、导出集中在主菜单，同一工具组不堆积实心主色按钮 |
| 动效 | Hover/面板展开等 100～160 ms；可减弱；播放头与画布反馈不加人为缓动拖尾 |

控件实现必须共享 Theme、字体测量、布局、图标与状态，不按页面复制坐标常量。数值输入支持键盘编辑、单位、范围验证、失焦提交/取消规则；不能只用“点击循环几个预设值”。

2026-09-26 主菜单调整：取消自绘窗口控制及其命中拦截，由 Windows 处理最小化、最大化和关闭。应用标题区默认 32 DIP，菜单与设置根据 DWM 返回的原生按钮位置对齐，不显示工程名。工具按钮和录制来源卡片采用无常驻描边的底色层级，键盘焦点保留独立提示。本约定替代此前的 48 DIP 整行自绘方案，见[实现与验证](UI-Main-Menu-2026-09-26.md)。

### 3.2 图标与文案

- 播放/暂停、分割、缩放、适应视图、撤销/重做使用一套风格一致的 SVG；同样的放大镜不能兼作所有时间和镜头命令。
- 主菜单中的录制新视频、打开工程等命令保留图标与文字；编辑器已有图标按钮保留中文 Tooltip 和可访问名称。图标化不等于删除全部操作说明。
- 图标按钮提供中文 Tooltip、快捷键、可访问名称；录制准备与编辑器共用提示定位，贴近客户区边缘时移位或翻转，Tooltip 不改变布局。
- 实际测量文本；标题区不显示工程名，时间码/输入值/错误操作不能用裁切隐藏。长路径在详情里显示。
- 对齐数字、标签和输入区域，避免零散左右跳动；不靠固定高度塞多行中文。

### 3.3 状态不能混用

| 状态 | 语义与视觉规则 |
|---|---|
| Hover | 鼠标在控件上，轻底色；移出消失 |
| Pressed | 按下且未释放；释放、失焦或取消捕获立即清除 |
| Focused | 键盘操作目标，用独立焦点环，不表现为按钮保持按下 |
| Selected/On | 只用于开关、标签页、所选工具等持久状态；普通命令不保留 Selected |
| Disabled | 清晰的禁用态，无鼠标或快捷键副作用；原因可查 |
| Busy | 仅作用于实际受影响操作，有进度/取消；不能冻结整个窗口 |

播放按钮反映播放意图且能立即取消；画面是否已经开始播放另行采样，不能用按钮变为暂停图标证明播放延迟合格。

## 4. 核心操作契约

### 4.1 时间线与播放

- 单击标尺跳转；按住标尺/播放头连续拖动，画面持续更新。拖动开始记录此前播放状态，松手精确定位后仅在此前播放或有新播放意图时恢复。
- 播放头跟随指针，视频可短暂使用受限近似帧；不显示黑帧，不被积压旧请求拖回早先位置，不只在松手后更新。
- 空格在非文本编辑/弹出菜单环境切换播放意图；定位中也可接收，再按取消。数值编辑时空格不得触发全局播放。Tab 明确聚焦的普通按钮用 Enter/Space 激活，焦点策略与全局快捷键不能双执行。
- 单击视频/镜头主体选择对象，不隐式把当前播放头强制跳回片段开始；标尺承担定位。双击对象可进入对应编辑态，不与单击混淆。
- 拖动镜头主体只移动镜头；拖动视频边缘裁剪；视频主体在本轮只用于选择，不暗示支持重排。
- 拖动两端在边界前停止，不能产生负时长、重叠或越界。显示临时时长，Esc 恢复手势前状态，一次手势只产生一次撤销。
- 时间线支持滚动条/Shift+滚轮水平平移、Ctrl+滚轮以鼠标为锚缩放及“适应全部”；触控板水平滚动不转换为缩放。
- 手动平移后不立刻被播放自动跟随拉回；提供显式恢复跟随。拖至视口边缘可自动滚动，速度有上限。
- 裁剪吸附为可选辅助，默认仅吸附播放头和相邻边界；6 DIP 距离内提示，可按 Alt 暂时解除；不吸附每个点击事件造成抖动。
- 缩略图异步生成、可见范围优先、预算有界；不在拖动时逐帧从文件重建。

### 4.2 镜头与外观

- 选中镜头后显示上下文属性：开始、结束、时长、倍率；焦点在画布中拖动，方向微调不是常驻主入口。
- “时间线放大”与“镜头放大”必须在位置、图标提示和快捷键上可区分。
- 修改镜头或外观时预览应连续反馈；提交后不能再进入同步长解码。撤销/重做覆盖视频、镜头、外观和光标，而非只撤销其中一种。
- 自动初稿可选择应用/旁路；恢复自动初稿为显式、可撤销操作，不得无提示清除手工编辑。旁路只关闭效果，不删除镜头数据。
- 图片背景选择后显示名称/缩略图、替换/移除；必须复制到工程，不依赖外部图片继续存在。

### 4.3 录制器、工程与导出

- 录制器首屏只保留来源、录制规格、无音频说明、保存位置和开始录制；高级诊断收起。
- 录制时停止按钮突出，时长和状态可见；不能把“已停止点击”当成文件已完成。收尾完成后在同一主窗口进入编辑器。
- 标题栏设置、新录制、打开工程入口固定；录制准备页可继续最近工程。新录制只切换到准备状态，实际开始仍由录制按钮触发。设置负责主题和诊断，原有编辑参数按组保留，不能丢失焦点 X/Y 或光标倍率等数值入口。
- 无工程、加载中和失败均保留主窗口；打开失败保留原有效工程。只有关闭主窗口请求退出应用，新录制或打开其他工程不销毁应用主窗口。
- 保存状态为“未保存 / 保存中 / 已保存 / 保存失败”；失败不能清除 Dirty。Ctrl+S 保存，Ctrl+Z/Y 撤销/重做。
- Esc 首先取消拖动、输入或弹窗；空闲时不关闭工程。离开当前工程和关闭主窗口都处理“保存 / 不保存 / 取消”；取消或保存失败清除待切换意图，保留当前修改。导出未完成时，离开工程先确认是否取消任务。
- 导出配置、进度和结果使用标题栏下的主窗口子面板，不创建第二个业务主窗口。面板显示分辨率、帧率、时长、输出位置和无音频说明；收起或 Esc 不取消任务，取消导出使用明确的独立按钮。
- 导出启动前提交有效输入并刷新参数，开始运行后参数对应冻结的编辑快照；继续编辑不改变本次输出。再次导出时刷新最新参数，工程切换后不保留上一工程的输出位置。
- 成功明确给出打开视频和打开文件位置；失败保留编辑结果，简短中文原因加“查看详情/复制诊断”，不在时间线挤满英文异常。

## 5. 页面与状态交付清单

当前候选仍须对以下真实状态分别保留操作和视觉证据，不把历史原型或自动测试视为本轮人工验收完成：

1. 录制器：待录制、录制中、收尾中、失败/可恢复。
2. 编辑器：未打开、加载、暂停、播放、连续 Scrub、视频选中、镜头选中、属性输入、保存失败。
3. 导出：设置、进行中、取消、成功、失败。
4. 控件状态页：普通按钮与开关的 Hover/Pressed/Focus/Selected/Disabled。
5. 标准窗口和紧凑窗口各一套真实内容布局；缩放不同、长中文名称、非 16:9 源都要覆盖。

紧凑验收以 1024×720 DIP 客户区为起点，标准 1440×900 DIP 客户区。高 DPI 且物理工作区不足时，自动折叠 Inspector/次要工具，至少保留预览、播放和时间线；不得创建大于工作区且无法触达关闭/保存的窗口。

设计确认后 R2 必须用真实程序逐项对照。截图证明排版，交互记录证明操作；二者都不能由布局单元测试替代。

## 6. 体验放行规则

所有帧延迟、拖动连续性、DPI、快捷键、闪烁和重开条件以[验收计划](Recording-Editing-Acceptance-Plan.md)为准。任何一个正常工程存在“拖动无响应”“按空格无反馈”“画面长时间不跟随”“按钮永久按下”“文字覆盖标尺”，均不得标记 UI/UX 完成。

用户对最终视觉不认可时，状态为待修改，而不是“自动测试已通过所以视觉通过”。
