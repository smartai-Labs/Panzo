# v13 · 12 项桌面 UI 审查整改

日期：2026-10-09。对应 [12 项审查](UI-Commercial-Readiness-Audit-2026-10-09.md)，承接 v12.7 插件生命周期修复。

**12 项均已推进到代码整改或明确的发布验收门槛。本轮交付可运行的 v13 候选；尚不能宣称全部商业验收完成。** 大图响应已有明显改善，但尚未达到 16.7 ms 优化目标；真实 Windows 11、混合 DPI、Narrator 等专项仍待实机验证。

## 启动与范围

- [启动 v13](../target/desktop-v13/release/panzo.exe)。已安装插件沿用原配置；首次使用可在顶部“插件”安装同目录的 [声音与字幕插件包](../target/desktop-v13/release/panzo-media-tools.panzoplugin)。
- 本轮保持原生桌面架构、统一 Inspector、全宽时间线、设置与插件独立窗口。没有增加第二套侧栏。
- 验证使用隔离配置、合成图片和测试工程副本；没有关闭用户实例、修改用户工程、录制真实麦克风或调用收费 AI 服务。
- 当前实测环境为 Windows 10 19045。正式目标仍为 Windows 11；[发布验收矩阵](UI-Release-Gates.md) 明确区分开发机回归和目标平台验收。

## 本轮发现并修正的回归

1. 固定操作区初版仍被旧的滚动布局再次移动。已让布局批次对同一 HWND 仅提交最后坐标，并排除固定按钮的滚动定位；原生断言覆盖滚动前后位置与可见性。
2. 新增的小位图缓存最初在线程析构时释放 GDI 资源，导致退出码虽为 0，仍生成崩溃转储。已改为最后一个绘图会话结束时主动清空；无会话的绘制不进入缓存。新增生命周期单元测试，并用退出脚本检查**退出码和本轮测试 PID 的新转储**。
3. 统一提示窗初版残留系统亮框、单 LF 正文换行不正确。已删除系统模态边框，使用主题分隔色细线、规范换行与正文排版；截图复核和退出回归验证。

早期失败证据保留在 `acceptance/ui-v13-20261009/final-exit` 与 `exit-cache-diagnostics.json`。诊断文件的 possibleAppFrames 是符号化的候选栈地址，不能当作完整展开栈；GDI 异常模块、缓存析构候选帧与修复后回归共同定位问题。早期结果不作为最终通过证据。

## 验收边界

- 响应探针测量 Win32 尺寸变更、消息往返和待处理绘制，包括系统调度；**不是 FPS、实际屏幕帧间隔或输入到呈现延迟**。绘图像素采样也不能排除采样间更短的闪烁。
- 预览层级在文档变化时生成，以少量额外内存换取连续缩放响应；导出、OCR 和文档原始像素不走降采样预览层。
- 本轮只读 Windows 辅助功能偏好，没有修改用户系统设置。完整无障碍结论需要真实设置组合、纯键盘与 Narrator 验收。
- 单机短时资源检查不能代替长时间剪辑、低配 GPU 或真实麦克风/网络服务异常测试。
- 完整商业发布须按 [发布矩阵](UI-Release-Gates.md) 补齐 A01、A06、A11 的剩余验证与性能目标；当前候选适合继续体验和验收。
