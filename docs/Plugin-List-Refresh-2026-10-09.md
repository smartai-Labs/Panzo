# 插件管理列表刷新修复（v11.1，2026-10-09）

用户反馈在顶部「插件」管理窗口找不到媒体插件。检查时，当前程序为 v11；用户本机 `Panzo/Plugins/registry.json` 已包含 `panzo.media-tools` 1.0.0，未停用，安装文件的 SHA-256 与清单一致，确认无需重新安装。

代码检查发现两处刷新缺口：插件管理器的「刷新」只重新读取进程内的缓存，未重新读取磁盘登记；顶部「插件」复用已有窗口时直接显示窗口，也绕过了列表更新。其他实例安装插件或旧窗口仍持有缓存时，列表会与安装记录不一致。由于窗口查看工具连接失败，本次未能直接确认用户当前屏幕是否正由这条路径触发。

修复内容：

- 每次打开管理窗口或点击「刷新」均重新读取并校验插件登记。
- 安装成功后返回管理窗口，自动选中并滚动到刚安装的插件。
- 底部显示已安装独立插件数量，或刚安装插件的名称与启用状态。
- 登记损坏时保留上一次有效的内存状态及正在执行的任务计数，并显示错误。

启动：正常退出现有 Panzo（包括托盘后台），运行 `target/desktop-v11.1/release/panzo.exe`。此前安装的媒体插件保留，无需重复安装。

验证：8 项插件管理单元测试通过，覆盖跨实例安装后刷新、启用状态更新、异常登记刷新、安装、更新、回退、停用和卸载。原生窗口显示复测未完成：Computer Use 的 Node 进程连续两次启动失败。
