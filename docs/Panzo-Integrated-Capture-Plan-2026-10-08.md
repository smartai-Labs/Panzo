# Panzo 一体化截图、贴图与录屏方案

日期：2026-10-08。状态：A 阶段已交付；B 阶段核心流程已实现并完成本机回归，混合 DPI 多显示器实机验收待补测。详见 [A 阶段说明](Integrated-Capture-Stage-A-2026-10-08.md) 与 [B 阶段说明](Integrated-Capture-Stage-B-2026-10-08.md)。本文取代上一轮“轻量截图作为配套”的产品取舍；历史可行性分析保留作技术依据。

## 1. 产品目标与完成标准

定位：一个安装包，完成截图、标注、贴图参照、录屏、基础编辑和图片／MP4／GIF输出。核心目标是减少用户安装和切换软件的次数。

围绕三类任务构建产品：

- 工作沟通：截取问题 → 标注／遮挡 → 复制发送，或录一段操作 → 导出GIF。
- 桌面参照：截图／剪贴板图片 → 贴在桌面 → 对照操作 → 隐藏与恢复。
- 演示教学：录制屏幕与声音 → 开关鼠标跟踪缩放 → 剪辑与修饰 → 导出MP4。

截图、标注、贴图是核心能力，必须进入第一个完整版本的验收范围。滚动截图和OCR也纳入路线图，按后续阶段交付。功能多不应增加日常操作步骤：快捷操作直接完成，复杂设置逐级展开。

“一个应用”的约束：统一安装、更新、快捷键、设置、历史和素材；核心工作流离线可用；编码器由Panzo随包管理，用户无需安装FFmpeg、Python或独立转换软件。专业配音、复杂多轨剪辑、直播推流、团队云协作暂不属于本版承诺。

## 2. 入口与典型操作

主窗口提供“截图”“录屏”“最近内容”三个入口，另有“导入文件”。托盘菜单和全局快捷键覆盖截图、贴图、录制启停、全部贴图显隐。快捷键可自定义，检测冲突后提示替代组合；提供熟悉的截图工具键位预设，切换须由用户明确选择。

快捷截图不先打开视频编辑器：快捷键 → 选区 → 浮动标注工具条 → 复制／保存／贴图。截图工具条可保留选区并切换到区域录屏；开始录制前恢复实时画面、隐藏截图工具条并显示倒计时。

区域录屏：快捷键／录屏入口 → 选择显示器、窗口或区域 → 确认鼠标与声音选项 → 录制 → 停止后选择“快速导出”或“继续编辑”。快速导出和编辑器使用相同成片规则。

贴图：截图后按贴图按钮，或将剪贴板图片／本地图片贴为独立置顶窗口。主窗口关闭到托盘后，贴图和快捷键仍可用；设置明确区分“关闭到托盘”和“退出应用”。

最近内容统一展示截图、录制工程、导出文件，可搜索名称、打开、编辑、复制、贴图或定位文件。工作历史和系统全局剪贴板监听是不同功能，首版只记录用户在Panzo中主动处理的内容。

## 3. 截图与贴图：对标Snipaste的核心体验

Snipaste官方将精准截图、标注、置顶贴图、缩放透明度、穿透及状态恢复列为核心能力。Panzo以这些常用任务作为对标范围；下表为Panzo自己的设计要求，并非宣称已实现或逐项兼容所有Snipaste版本。[Snipaste官网](https://www.snipaste.com/)

| 模块 | 首个完整版本要求 | 后续增强 |
|---|---|---|
| 截图选择 | 区域／窗口／全屏，窗口吸附，放大镜，物理像素尺寸，键盘微调，延时，上次区域 | 更细的UI控件吸附、固定比例预设、重复区域捕获 |
| 屏幕适配 | 多显示器与混合DPI截图，负坐标，跨屏选区，选区边缘不偏移 | HDR色彩校准与更多显示组合专项 |
| 标注 | 矩形、椭圆、直线、箭头、画笔、荧光笔、文字、序号、马赛克、模糊、实心遮挡；颜色／粗细／字号；撤销重做 | 对齐分布、批量样式、更多形状 |
| 图片编辑 | 裁剪、旋转、翻转；已有标注可选中、移动、修改、删除 | 拼图、画布扩展、模板批量处理 |
| 输出 | 复制图片、PNG／JPEG保存、快速保存、另存为；可选统一背景与阴影 | 更多格式与批量尺寸处理 |
| 贴图 | 多张独立置顶、拖动、缩放、透明度、旋转翻转、鼠标穿透、锁定、缩略／展开、单张及全部显隐 | 分组、组合布局、GIF贴图播放 |
| 贴图编辑 | 在贴图上继续标注，保留可编辑内容，再复制或保存 | 文字／颜色信息直接转贴图 |
| 恢复 | 最近截图、最近关闭贴图恢复；记忆贴图位置／缩放／透明度；重启恢复；显示器拔除后移回可见区域 | 分组备份与多套桌面工作状态 |
| 取色 | 放大镜下取色，复制HEX／RGB | 颜色历史、色板 |

鼠标穿透必须有“恢复交互”全局快捷键与托盘入口，避免贴图无法再操作。官方FAQ也说明了穿透后的输入转交行为及快捷键恢复方式。[Snipaste FAQ](https://www.snipaste.com/faq.html)

采用“原始图片 + 标注对象 + 裁剪／外观设置”的图片文档模型。编辑保留对象，输出时统一合成。遮挡、马赛克与模糊在复制／导出时实质合成到像素；复制出的图片不得附带隐藏原图或可撤销标注。Panzo内部保留的原图须与用户发出的扁平图片明确区分。

PNG输出与剪贴板图片以原始像素为准，贴图缩放只影响查看；提供明确的“按显示尺寸输出”选项。中文输入法、DPI变化、文字换行和字体回退进入验收范围。多贴图设置内存／磁盘预算，闲置贴图按需重绘，避免常驻解码视频或持续刷新屏幕。

## 4. 录屏与鼠标跟踪缩放

### 4.1 录制设置

录制面板：来源（显示器／窗口／区域）、目标帧率（30／60）、系统声音、麦克风、鼠标显示、点击提示、鼠标跟踪缩放、倒计时。普通录屏和演示录屏预设分别保存，应用设置只决定新工程默认值。

区域录制首期支持单显示器内固定矩形，显示准确尺寸，保存前裁剪；多显示器截图可以先完成，跨显示器录制需要额外帧合成和时序处理，列入后续阶段。编码偶数尺寸通过区域内收或区域内画面填充处理，不能向外扩大选区。录制中移动选区列为高级模式。

录制悬浮条提供暂停／继续、停止和鼠标跟踪缩放开关，显示当前状态。悬浮条和选区边框应从自身录制中排除；无法可靠排除时放在录制区域之外并给出可见提示。停止后可直接快速导出，也可进入编辑器。

### 4.2 三个独立鼠标选项

| 控件 | 开启时 | 关闭时 |
|---|---|---|
| 显示鼠标 | 在成片显示鼠标，可调样式和大小 | 成片不显示鼠标 |
| 点击提示 | 显示点击波纹等提示 | 不显示提示 |
| 鼠标跟踪缩放 | 在选定捕获范围内自动调整取景和倍率 | 旁路自动镜头，普通录屏保持原始取景 |

这三项相互独立：隐藏鼠标仍可使用跟踪缩放；关闭跟踪也可显示鼠标和点击提示。显示鼠标的开关不应偷偷改变运镜模式。

自动模式包含“平滑跟随”和“点击聚焦”。主界面只展示跟踪缩放开关，模式与倍率放在展开设置中。普通录屏首次默认关闭；演示预设可默认开启，并分别记忆用户最近选择。

平滑跟随以连续鼠标轨迹为输入，使用中央安全区、平滑和边界约束；小幅移动保持镜头稳定，鼠标接近边缘时再移动视口。建议从1.5倍默认倍率开始验证，提供少量倍率与跟随速度选项。点击聚焦保留现有点击驱动逻辑。鼠标离开选区后不追踪区域外位置，按可配置的短暂停留和平滑回全景处理，禁止露出捕获范围以外内容。

### 4.3 录前、录中、录后三处一致

- 录制前设置决定本次录制初始状态，并在录制悬浮条显示。
- 录制中切换写入带时间戳的启用区间。新状态从对应时刻生效，平滑进入／退出，不能回溯影响前面所有片段。
- 录制后可按整段或区间调整状态、模式、倍率，撤销重做、保存重开后保持一致；MP4、GIF和当前帧输出使用相同规则。
- 原始选区视频保留原始取景，自动镜头作为可修改的效果保存；录制画面不被不可逆地放大裁掉。录制中的开关控制结果视频的效果区间，不会放大用户正在操作的桌面。录制时的效果预览可后加，不能影响原始录制吞吐。
- 自动跟踪开关只控制自动轨。用户手工镜头有独立轨道和开关，优先级高于自动镜头；另提供“查看原始画面”总旁路用于对照。关闭自动跟踪不删除或重建手工修改。

实现建议：项目保存分离的自动镜头策略、启用区间、自动生成轨、手工镜头轨与生成版本。启用区间使用源时间轴，切分／删除／变速后由已有映射转换，暂停时段不进入素材时间。旧工程的camera_enabled按既有整体旁路语义迁移，保留原有外观；新的自动轨开关不能直接复用为覆盖全部手工镜头的单一布尔值。

当前已有可复用基础：WorkbenchSettings.camera_enabled、编辑撤销以及FrameEvaluator的整体旁路；新录制默认关闭。当前planner的decisions来自点击事件，连续跟随是新增能力。[render.rs](../crates/panzo-core/src/render.rs#L350)、[editor.rs](../crates/panzo-windows/src/platform/editor.rs#L512)、[planner.rs](../crates/panzo-core/src/planner.rs#L185)、[使用说明](RE-MVP-User-Guide.md)。

## 5. 声音、编辑与输出

声音需要覆盖系统声、麦克风、两者混合、分别静音及音量。录制前提供电平检查；有条件保留分轨便于后期调整。设备变化、暂停继续、时间戳和音画同步必须做连续录制验证。

视频编辑复用现有剪切、删除、变速、裁剪、背景和镜头；增加外部MP4导入、选定时间区间导出和当前帧截图。外部素材无Panzo鼠标事件时仍可剪辑和手工镜头，自动鼠标跟随明确显示不可用；GIF导入／转视频作为后续格式能力。

| 输出 | 面向用户的设置 |
|---|---|
| PNG／JPEG | 范围、背景／透明度（PNG）、质量（JPEG）、复制或保存 |
| MP4 | 原尺寸／预设尺寸、30／60 fps、清晰／均衡／小文件、音频、输出片段 |
| GIF | 片段、宽度、10／15／20／25／30 fps、循环、质量／抖动、预览、取消；默认15 fps、限制默认输出宽度 |

录制帧率与导出帧率独立。降帧率保持原时长；升帧率不承诺增加真实运动细节。GIF实际帧延时需累计分配，以处理10ms时间粒度；导出显示进度和估计体积，估计不是硬保证，失败或取消清理临时文件。

所有输出以编辑后的统一场景为准，截图标注／视频注释共享基础对象和样式，但视频注释另有出现时间与坐标锚点。屏幕贴图是桌面参照物；将贴图加入成片必须通过“添加到视频”创建独立素材，避免不清楚哪些桌面辅助窗口被录入。

GIF第一版可以把编辑后的MP4转码，编码后端由Panzo安装包携带；后续直接编码合成帧，减少临时文件和重复有损编码。不能将“请用户自行安装转换软件”作为正式交付。依赖构建与分发许可要随包核验，FFmpeg不同可选组件会改变许可条件。[FFmpeg官方说明](https://ffmpeg.org/legal.html)

## 6. 内部结构与现有代码接入

保留Rust与现有Win32／D3D11／Media Foundation基础。先做模块边界，不为功能整合整体更换UI技术。

| 模块 | 责任与边界 |
|---|---|
| AppShell | 托盘、快捷键、主窗口、设置、任务调度；截图和贴图按需工作，视频编辑器延迟初始化 |
| CaptureSelection | 显示器／窗口枚举、区域选择、DPI与物理像素变换；截图与录屏共用 |
| CaptureService | 单帧抓取、连续录制、保存前裁剪、光标事件、音频、暂停与恢复 |
| ImageDocument | 原图、标注、裁剪和样式、撤销与持久化、复制／保存合成 |
| PinManager | 贴图窗口生命周期、穿透恢复、位置／缩放／透明度、重启恢复 |
| CameraController | 连续跟随与点击聚焦策略、源时间启用区间、手工轨优先级、边界约束 |
| Render／Export | 共享场景和已有FrameEvaluator／Compositor，PNG／MP4／GIF后端、导出队列与取消 |
| AssetLibrary | 截图、工程、导出和贴图索引；保留策略与缓存配额分开，清缓存不删原文件 |

源码改动重点：recorder.rs接区域、可配fps与时序；core/events.rs接区域坐标和区外过滤；core/planner.rs新增连续跟踪；core/editor.rs及render.rs接镜头策略与区间；export.rs接输出配置／区间；fmp4_writer.rs调整当前20Mbps下限的分享策略。新增截图、标注、贴图模块，避免都塞入现有编辑器窗口文件。

原始视频与图片、文档编辑状态、派生缓存分离。保存使用现有原子提交思路；快照／贴图关闭／历史删除／文件删除在界面中区分。回收历史时固定贴图和用户主动保留的素材免于自动清理。导出冻结编辑快照，避免导出中调整参数导致文件内部效果不一致。

## 7. 分阶段实施与验收

下列阶段都属于同一个产品计划；A只代表首个可用切片，A+B+C完成后才将“截图＋贴图＋录屏常用工作流一体化”作为对外完成目标。阶段交付以验收结果为准，日历工期需完成基础原型后估算。

| 阶段 | 实施内容 | 放行条件 |
|---|---|---|
| A：基础与快速捕获 | 复验现有录制／导出；共享坐标和选区；托盘快捷键；基础截图标注；简单置顶贴图；区域录屏；录前镜头开关；参数化输出与GIF | 从一次选区可截图／录制，开关生效，导出内容一致，区外像素未写素材；基本截图不启动重型编辑器 |
| B：截图贴图完整工作流 | 完整标注编辑、跨屏DPI、贴图透明／穿透／显隐／恢复、取色、历史、快速复制保存 | 连续完成截图标注发送、贴图参照、多张贴图管理和重启恢复，无需其他截图软件 |
| C：录屏演示完整工作流 | 录中及区间运镜开关、连续平滑跟随、暂停继续、系统声／麦克风、MP4导入、区间导出、分享预设 | 完成带声音教程与无声GIF；开关可录后修改，音画同步，剪辑后镜头时间准确 |
| D：继续减少辅助软件 | OCR复制文字、滚动长截图、拼图、批量压缩／格式转换、贴图分组及GIF播放、视频标注 | 每项以具体任务替代为验收；OCR离线模型／能力随安装管理；滚动拼接有失败反馈和手动纠正 |

OCR和滚动截图应进入明确待办，不能因为系统或其他软件已有而长期排除；其优先级在截图贴图与录屏核心稳定后。云端上传／同步另行评估，普通文件复制、保存和拖拽分享在本机即可完成。

十个目标任务：

1. 截取应用局部、加箭头和中文说明、遮挡信息、复制到聊天或文档。
2. 把截图贴在桌面，缩放半透明对照，一键恢复可交互状态。
3. 多张贴图全部隐藏／恢复，重启后继续工作。
4. 跨不同缩放比例显示器截图，输出像素与选区一致。
5. 框选区域录制普通视频，显示鼠标但不缩放。
6. 同次录制中开关跟踪缩放，录后调整，MP4和GIF效果一致。
7. 鼠标未点击但连续移动时，平滑跟随仍能工作且画面不露边。
8. 系统声和麦克风录制、暂停继续后音画同步，剪掉中间内容再导出。
9. 导入已有MP4、剪出短片、导出不同尺寸与帧率的GIF。
10. 从编辑后视频导出当前帧，继续标注并贴到桌面。

A+B+C应在干净Windows测试环境安装一个Panzo包后完成上述任务，不要求另装其他应用。性能验收单列冷／热启动、截图调用延迟、中文文字清晰度、空闲CPU／GPU／内存、多贴图资源、1080p／1440p录制、不同DPI、长视频导出及崩溃恢复；阈值在基准机原型测量后冻结，不能将现有测试结果直接作为新功能通过证据。
