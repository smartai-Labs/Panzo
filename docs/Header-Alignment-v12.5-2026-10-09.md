# 工作台顶部布局 v12.5

2026-10-09。候选程序：`target/desktop-v12.5/release/panzo.exe`。已安装的媒体插件兼容，无须重装。

## 本次修正

- 视频预览上方只保留一行工具栏：左侧折叠按钮、保存状态，右侧缩放比例、恢复居中并适应窗口。
- 移除自动生成的工程名和分割、删除、裁剪等常驻提示，腾出预览空间。状态显示“已保存”“未保存”或“保存中…”。需要处理的警告、错误仍会显示。
- 删除工作区设置齿轮和诊断菜单，移除镜头诊断快捷键；录制准备页的“录制设置”直接进入录制选项。主题使用主窗口右上角太阳 / 月亮按钮。
- 自绘标题栏的最小化、最大化 / 还原、关闭按钮采用统一的客户区坐标；绘制和非客户区命中测试共用矩形。左侧菜单及主题按钮与它们垂直居中对齐，修正最大化后沿用 DWM 窗口坐标产生的向上偏移。
- 预览区域随新增空间调整，GPU 显示区域和鼠标操作区域保持一致。

## 验证

- `cargo test -p panzo-windows --offline --lib -- --test-threads=1`：232 通过，42 个显式环境测试跳过。
- 原生 `native_titlebar_ui_review`：1 通过。在独立配置和合成工程中验证真实主窗口普通、最大化、还原状态；深色和浅色主题；菜单、主题及系统按钮居中；每个系统按钮上中下三点命中；折叠按钮、保存状态和预览适配控件同排；GPU 边界；未保存状态与撤销；程序化最小化 / 还原。
- 布局与命中测试覆盖 96 / 120 / 144 / 192 DPI，标题栏还覆盖 168 DPI。跨显示器实际 DPI 切换及真实鼠标点击系统按钮未在本轮自动化中覆盖。
- 测试仅禁用自己的测试线程 IME，生产程序输入法行为未改动。测试未操作用户工程或关闭现有应用实例。

验证日志及截图位于 [验收目录](acceptance/header-v12.5-20261009/)。
