# 深色主题、属性面板与时间线上方参数 — 2026-09-19

候选：`dist/Panzo-RE-MVP-ui-theme-20260919/panzo.exe`。上一轮程序保留。

## 使用变化

- 录制器和编辑器右上角新增明确的齿轮设置入口。在设置中选择“浅色主题”或“深色主题”，立即生效，下次启动沿用选择。未打开工程也可以设置。
- 两种主题覆盖录制器、编辑器、轨道、按钮、输入框、提示和导出面板。主题只影响应用界面，不改变录屏、工程背景、预览画面或导出结果。
- 右侧属性栏改为固定的“背景”“画面”“光标”分组。背景模式按钮与色块、对齐的参数数值和滑杆使用统一间距与圆角；默认宽度调整为 288 DIP，仍可拖动调宽、收起、滚动。
- 视频片段的入点 / 出点、镜头的开始 / 结束 / 倍率 / 居中焦点，移至时间线工具条下、标尺上方的独立参数条。选中片段时显示对应内容，宽窗口补充时长；关闭属性栏仍可使用这些参数。
- 片段参数条保留固定高度，切换选择不推挤属性栏或轨道。时间线默认高度同步调整，仍随用户拉高重新分配轨道空间。
- 视频轨道中的片段信息标签改为顶部紧凑标签，不再随轨道高度形成大块面板。
