# Panzo 原生界面与交互问题筛查

日期：2026-10-09。范围：用户提出的 12 项问题，以及相关工作流中的状态、命令、渲染和素材管理缺陷。

本轮只完成审查、复现和报告，没有修改产品源代码，也没有替换正在使用的应用。上一轮验证覆盖了启动和部分状态保留，遗漏了连续绘制、下拉展开、录制浮窗等关键交互状态。

## 审查依据与结论

审查对象为 target/desktop-v3/release/panzo.exe，构建时间 2026-10-08 13:45:07 UTC。可执行文件 SHA-256 为 4BE86C0C11DC50D48A8A2749BCBE9D37C912B48CF514889D214E4ACB4503F387；构建清单的 149 个源文件逐一核对，均与当前文件一致。

证据分三类：

- **运行复现**：在隔离配置与合成图片中运行上述候选版本，确认连续绘制会露出画布底色。
- **代码确认**：已定位到具体实现与消息/状态流；涉及用户操作的完整序列仍需加入后续运行验收。
- **待验证风险**：存在边界条件或状态语义风险，尚未进行对应运行复现，不能写成已经发生的故障。

主要问题同时存在于四层：原生控件没有覆盖全部显示状态、画布重绘流程暴露中间帧、工作区与表单的状态生命周期混杂、图片编辑与素材管理缺少完整交互模型。仅调整颜色和间距无法完成这次修正。

优先级：P0 表示影响持续操作或可能操作错误内容；P1 表示本次改造的必需项；P2 表示跟随基础功能完善的增强项。P1 并不意味着可以留到交付后。

## 绘制闪烁：已经复现，不能当作样式问题处理

采用全新隔离配置，打开 4000 × 2500 的纯色测试图片，连续发送画笔移动操作，并在**远离笔迹、内容应始终不变**的位置采样屏幕像素。未使用用户的实际图片或 OCR 服务，也未关闭用户已有应用进程。

约 2.79 秒内采样 280 次，其中 217 次读到了画布底色 #1E2220，而不是图片颜色 #E8EAEE；两种颜色之间发生了 39 次切换。绘制结束后恢复图片颜色。这直接证明绘制期间存在可见的清底中间状态。

这些是像素采样次数，**不等同于显示帧数、闪烁帧率或丢帧比例**；本次也没有分别测量以下每个代码因素的贡献。

证据：[采样摘要](acceptance/ui-audit-20261009/drawing-audit.json)、[原始采样](acceptance/ui-audit-20261009/drawing-samples.json)、[绘制前](acceptance/ui-audit-20261009/drawing-before.png)、[绘制后](acceptance/ui-audit-20261009/drawing-after.png)。

代码链路：

1. picture_window.rs:1246–1291 在拖动中请求重绘；capture_tools.rs:619–622 对整个窗口无效化。
2. picture_window.rs:1422–1427 直接把 BeginPaint 得到的屏幕绘制上下文传入绘制函数；:925–933 先填满背景，:960–978 再获取图像并绘制。
3. picture_window.rs:961–968 在存在待绘制标记或所选对象时绕过缓存。image_document.rs:271–308 会克隆原图、重画标注并执行变换；capture_tools.rs:572–587 还检查所有像素的透明度，透明图片可能再次复制合成。
4. picture_window.rs:1466 已抑制原窗口的 WM_ERASEBKGND，但 :373 安装的通用表面子类在 desktop_ui.rs:309–314 仍可先填满背景，形成另一条擦除路径。

修复应包括完整帧缓冲、静态内容缓存、交互预览层和画布专属擦除策略；单独再加一次 WM_ERASEBKGND 拦截不足以覆盖上述链路。不要用减少鼠标反馈、隐藏画布或拖完才显示笔迹来掩盖问题。

视觉原则：

- 输入框和输出框**不使用亮边、立体边、发光外框**。以背景层次、留白和低对比分隔区分区域；键盘焦点采用内部短标记或轻微背景变化，不恢复一圈亮框。
- 深色保留现有主体明度；按钮、选中底色和滚动条转为中性体系。浅色采用白色主体与浅灰辅助区。少量低饱和蓝可作为主动作的候选强调色，具体数值在实机状态对照后确定。
- 控件按桌面工具的密度设计：紧凑、对齐、稳定；减少多重卡片、重复标题和占空间的说明。展开内容也必须遵循相同字体、间距与颜色。
- 应用自有浮窗、菜单、设置、插件、OCR 面板和导出面板统一设计。打开/保存文件、选择目录继续使用系统文件选择器，不另造文件管理器。
- 单图标必须有准确语义、悬停提示、可访问名称、键盘焦点和禁用原因；不能把现有含义错误的图标直接去掉文字。

## 导航与工作区组织建议

以下是功能关系示意，不是视觉稿；后续设计仍以原生桌面应用为方向。

    同色标题栏：Panzo                                      最小化 最大化 关闭
    文件  编辑  视图  帮助  插件  设置                          太阳/月亮
    图片工具     录制与视频     素材
    当前工作区的操作工具栏（常用动作以单图标为主）
    文件 / 文档标签

菜单在内容区最上方，工作区标签紧随其后，长期保持位置不跳动。内容区移除重复的图标和 Panzo 字样；标题栏背景继续与主体协调，保留原生拖动、最大化、贴靠和关闭行为。

设置与插件采用主窗口所属的唯一弹窗；允许回到主窗口继续工作。点击重复入口只激活已有窗口。设置分类切换保存会话草稿，插件安装进度和结果留在同一管理窗口。关闭后，主工作区的文件、视图、播放位置和识别结果保持不变。

这项要求替代之前“所有功能都塞入主工作区”的处理方式。OCR 识别结果、导入完成和常规任务反馈仍留在工作区；不能借本次弹窗调整恢复自动弹结果窗口的行为。

## 三项需要完整交互模型的能力

### 目录组件

默认显示文件夹图标与路径，不展示常驻输入框。图标打开目录选择器；点击路径或编辑入口进入临时编辑，Enter 提交，Escape 恢复原值，选择器取消不修改。离开编辑时采用一致规则：有效值可提交，无效值保留编辑并显示就地提示。

长路径采用中间省略，提供完整路径提示和复制。支持空格、中文、UNC 路径，并校验不存在目录、权限和不可用位置。图标的主要行为严格是“选择目录”；在资源管理器中打开位置可作为单独动作。

需要统一覆盖：

- 批处理输出目录：workspace_image_tools.rs:23–29、101–103，以及 image_workflows.rs:187–204 的兼容入口。
- 素材库目录及结果位置展示：panzo-app 的默认库路径，image_ops、recorder_window、workbench_actions 的结果路径。
- 视频/GIF 导出位置：export_window.rs:943–963。将“输出目录”和“文件名/扩展名”明确区分，不能把完整文件路径当作目录交给选择器。
- 截图另存为保留系统文件保存对话框；打开项目应定位项目条目/目录，避免让用户手动找内部 JSON。

workspace_form.rs:41–52 当前仅有基础文本/下拉字段，需要共用目录字段与编辑状态，避免各页面自行拼接按钮和输入框。

### 图片视口、裁剪与上下文属性

缩放和平移属于每个文档的视图状态，不修改图像像素，不进入撤销栈，也不影响 OCR 和导出分辨率。滚轮缩放围绕指针位置，空格拖动平移；适应窗口与 100% 有明确入口。绘图、命中测试、选框和裁剪统一使用同一坐标变换。

裁剪建立独立预览会话：初始覆盖完整图像，角点及边缘可拖动，裁剪区可平移，区外遮罩可见。属性栏提供自由比例、原图比例、常用比例与像素尺寸。Enter/确认提交为一条撤销记录；Escape/取消完全恢复。工具切换的提交/取消规则需要明确，不能因松开鼠标就直接破坏原状态。

属性区按上下文更新：

| 上下文 | 应展示的属性 |
| --- | --- |
| 选择工具 / 已选对象 | 与对象类型匹配的属性、位置/尺寸和可用操作 |
| 画笔、线条、箭头 | 颜色、线宽及适用的线型 |
| 矩形等形状 | 描边、粗细、适用的填充选项 |
| 文字 | 内容、字体、字号、颜色；可编辑既有文字 |
| 模糊、马赛克 | 模式、强度或块尺寸 |
| 裁剪 | 比例、像素尺寸、确认、取消 |

没有相关参数时不显示无关输入项。属性值、选择状态和工具状态不得相互清空；实时预览与撤销事务分开管理。

### 素材与预览

素材库需要统一资产来源、缩略图、详情和预览。单击选中即可预览，空格打开快速预览，双击才进入相应编辑器；预览不会新建编辑文档或切走工作区。

图片支持缩放查看；GIF 支持播放/暂停；视频至少提供封面、播放/暂停与定位。加载、缺失文件、解码失败均有明确状态。复制、贴图、编辑、导出等动作按素材类型显示可用性。列表切换回来保留筛选、选择及滚动位置，缩略图按可见项加载并缓存。

## 建议执行顺序与交付检查

| 顺序 | 工作内容 | 本阶段必须验证的行为 |
| --- | --- | --- |
| 1. 渲染与编辑正确性 | 画布完整帧缓冲、缓存和擦除策略；菜单按焦点与工作区路由；选择/拖动/取消/撤销事务修正。 | 大图连续绘制时不露底；在视频页保存/撤销不会修改后台图片；Escape 真正取消；仅选择对象不破坏重做。 |
| 2. 共用控件与窗口状态 | 统一输入/输出框、滚动条、展开列表、颜色面板、菜单、录制浮条、目录字段；设置/任务草稿独立于窗口。 | 深浅主题均无亮边、旧式滚动条或展开后跳回旧样式；收起/重开不丢草稿和任务归属；目录选择与临时编辑一致。 |
| 3. 主框架与管理弹窗 | 菜单、工作区标签、主题图标、动作图标；设置/插件弹窗。 | 菜单顺序正确，无重复品牌占位；管理窗口唯一、主动打开；图片、视频、识别状态不因打开/关闭弹窗丢失。 |
| 4. 图片交互 | 每文档缩放和平移、裁剪会话、上下文属性、既有文字编辑及缩略图刷新。 | 放大后仍精准绘制/选择；裁剪边框可调整且确认/取消正确；属性匹配工具，导出尺寸不被视图缩放影响。 |
| 5. 素材与全流程验收 | 统一索引、各类型预览、列表状态保持、错误反馈；覆盖全部可达辅助窗口。 | 截图→编辑→识别→保存；录制→预览→导出；批处理→素材预览；插件安装→使用→返回，均保持操作对象和状态一致。 |

验收应覆盖真实运行状态：

- 绘制：至少持续 10 秒，包含高分辨率、透明图片、已有多层标注、拖动物体和模糊/马赛克。保留本轮原始采样作基线；重复采样结合实际屏幕观察，不能仅以“采样为零”排除极短闪烁。
- 编辑：选择后重做仍有效；拖动中 Escape、失去捕获和切换工具均结束正确；文字对象可再次编辑；裁剪覆盖整图时不丢边缘像素。
- 视口：适应/100%/手动缩放、鼠标中心缩放、空格平移、窗口改变尺寸、切换文档；光标与落笔坐标一致。
- 控件：深浅主题、正常/悬停/按下/禁用/聚焦、下拉展开与滚动、颜色面板、识别输出滚动、录制浮条、导出及辅助窗口；100%、125%、150%、200% 显示缩放下检查裁切和对齐。
- 管理：设置类别来回切换、草稿未保存、连接测试进行中关闭/重开、插件安装中关闭/重开；无重复窗口、无结果失联。
- 目录：选择器取消、手动输入取消、中文/空格路径、无效路径、网络目录、长路径、库位置变更；输出文件名与目录分别正确。
- 素材：图片/GIF/视频、更多列表项、超出旧缩略图门槛的文件、丢失文件、失败解码；预览不开编辑文档，返回后保留选择与滚动。
- 键盘：Tab 焦点、输入框复制/撤销、菜单快捷键、Escape/Enter、单图标提示及可访问名称，行为与当前焦点一致。

现有 workspace_review.rs:653、658 对“没有辅助顶层工具窗口”的断言需要随新需求调整：允许用户主动打开的唯一设置/插件窗口，同时继续拦截自动弹出的 OCR/结果窗口。

本轮未重跑完整编译和单元测试，因为没有产品代码变更。历史测试通过不能替代上述新操作序列与外观状态的验收。本报告列出的目标均为后续待实施内容；当前候选版本的闪烁和界面问题尚未修复。
