# Panzo UI 重构第一阶段报告

执行日期：2026-09-02（Asia/Shanghai）

## 阶段结论

旧版“macOS 风格 UI Foundation”视觉验收结论已撤回。本阶段完成 UI 基础设施和 Editor/Recorder 布局的第一轮结构性重构；代码、布局矩阵、窗口生命周期和 GPU Preview 自动验收已通过。Release Editor 已分别在 1440×900 外框和 1040×760 最小外框完成目标窗口截图复核，未再发现按钮文字溢出、时间尺文字重叠、工具/状态行重叠或右侧控件裁切；产品视觉是否达到预期仍由用户复验确认。

## 已完成

- Per-Monitor V2 DPI Awareness、DPI 变化处理和 DPI 缩放 Theme。
- 各支持版本均内置的 Segoe UI 字体层级、单行省略号和基于真实字体宽度的 Tooltip/时间刻度碰撞规避；避免缺少 Variable 字体时 GDI 回退到等宽系统字体。
- 32 个统一 24×24 SVG 图标及栅格化缓存；缩放、焦点和起止时间全部改成纯图标命令。
- Timeline 信息重新分行：Timecode 位于 Header，Ruler 独占一行，状态和视图统计分别占据底部左右区域。
- Inspector 使用全宽属性行；选中镜头摘要拆成三个固定单行，避免中文自动换行堆积。
- Recorder 五个主操作采用等宽响应式布局，并与 Editor 共享 DPI、字体、SVG 图标和文字截断规则。
- 布局改为使用真实 Client Rect，而不是把外框最小尺寸错误地当作客户区尺寸；修复 1040×760 外框下底部工具行、状态行重叠和最右按钮裁切。

## 自动验证

- `cargo test --workspace`：通过；`panzo-windows` 55 项测试通过，Workspace 其余测试通过，1 项人工 Golden 更新测试按设计忽略。
- `cargo clippy --workspace --all-targets -- -D warnings`：通过；`cargo build --release --workspace`：通过。
- Editor 多 DPI 客户区布局矩阵：96/120/144/192 DPI × 1024×720、1040×760、1440×900、2560×1440 均无 Ruler/Timecode、Status/Meta、工具/状态行或 Inspector 属性行几何重叠。
- 32 个 SVG 图标均可生成非空 Alpha Mask。
- Editor 自动窗口 Smoke：Window Created、GPU Direct、Present、CPU Readback=0、Graceful Close 均通过；Trim 仍为增量提交。
- Recorder Open Last Smoke：Window Created、Last Project Loaded、Graceful Close 均通过。

## 真实窗口复核

Windows Computer Use 原生通道在当前会话返回 native pipe unavailable，因此改为只捕获 Panzo 目标窗口的 `PrintWindow` 复核，不采集整个桌面。复核证据为 `.tmp/ui-refactor-release-final.png` 与 `.tmp/ui-refactor-minimum-window-final.png`。

## 已知独立缺陷

完整 Editor MVP 脚本使用 60 秒历史工程时，Queued Playback 延迟门槛未通过（约 2.2 秒）。`decode-seek-probe` 已确认该 fMP4 在 30 秒随机定位时跳过索引目标，Media Foundation 最坏退回第 0 帧并顺序解码约 1800 帧；这不是 Chrome 绘制造成的延迟。本阶段不通过放宽门槛或增大 UI 线程批次掩盖它，后续应从 fMP4 随机访问索引/Finalize 或解码器后台任务设计解决。
