# Panzo Editor Workbench MVP 第二个增量报告

执行日期：2026-09-01（Asia/Shanghai）

## 阶段目标

在 V0.1 Technical Foundation 上建立第一条录后编辑闭环：保留 Auto Draft，允许用户在时间线修改 Camera Segment 和基础画布样式，保存后由 Preview 与 Export 共同读取，不修改源视频或输入事件。

## 已交付

- 新增 [V0.2-Editor-Workbench-Spec.md](../V0.2-Editor-Workbench-Spec.md)，并在 V0.1 技术方案中记录 Editor-first 路线、T1 延期和自然度评审迁移。
- `panzo-core::editor` 提供 Camera Segment 新增、修改、移动、删除、Clamp、连续性修复和有界 Undo/Redo，以及 Workbench Settings Schema V1。
- `ProjectEditorSession` 首次保存创建 `tracks/camera.auto.json`，后续永不覆盖；当前 Camera、Workbench Settings 与 Edit History 分别持久化。
- Camera 与 Style 使用统一顺序 Undo/Redo；保存失败时尝试恢复上一份有效 Camera Track。
- Camera Regeneration 保留 `locked/userModified` Segment，并删除与人工范围重叠的自动 Segment。
- D3D11 Compositor 支持 Solid Background、Canvas Inset、Corner Radius、Shadow 参数和 Cursor Style；默认设置保持旧 Project 的全画幅输出。
- PNG/JPEG/BMP 背景会先解码验证，再按内容 Hash 原子复制到 Project `assets/`；Workbench 只记录安全相对路径，加载时拒绝解析到 Project 外部的资产。
- D3D11 Compositor 新增 Image Background Cover 采样；Preview、Render Hash Probe 与 Export 都加载同一份已解码 Project 背景。
- Preview、Render Hash Probe 与 Export 统一加载当前 Camera Track 和 Workbench Settings。
- 原 Preview Window 升级为 Editor Workbench：显示 Click Track、Camera Track、播放头、Segment 来源/修改状态；支持拖动 Segment 主体、修剪两端、调整焦点/scale/起止时间、新增、删除、保存、Undo/Redo、Reset Auto 和基础样式。
- Preview Canvas 显示所选 Segment 的焦点十字；可直接拖动焦点、滚轮调整 scale，并可导入背景图片、切换阴影强度。
- Recorder Window 的 `Preview` 入口升级为 `Editor`；CLI 新增 `editor` 与 `editor-acceptance-probe`。
- 新增 `scripts/verify-editor-mvp.ps1`，始终复制输入 Project 后再注入编辑，避免修改原始验收资产。
